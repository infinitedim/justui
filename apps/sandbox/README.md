# sandbox

The JustUI CLI sandbox. Everything under `lib/core`, `lib/tokens` and
`lib/widgets` is generated by `justui init` and `justui add --all` against the
local `../../registry`, so this app is the end-to-end check that installed
components compile, analyze and render. CI runs its analyze and tests as a
pub workspace member.

Never edit the generated folders by hand. Regenerate them with the recipe in
`.agents/rules/flutter.md` (section "apps/sandbox (generated)").
