# Instalasi

JustUI menyediakan alat baris perintah (CLI) untuk menyalin komponen ke dalam proyek Flutter Anda dengan cepat.

## Langkah 1: Aktivasi CLI secara Global

Aktifkan package `just_ui_cli` secara global menggunakan SDK Dart:

```bash
dart pub global activate just_ui_cli
```

## Langkah 2: Inisialisasi Proyek

Jalankan perintah berikut di direktori root proyek Flutter Anda:

```bash
just_ui init
```

Perintah ini akan membuat file konfigurasi `just_ui.json` serta mengunduh paket core dan token ke dalam proyek Anda. Anda juga akan ditanya pilihan preset visual utama (seperti `default` atau `neobrutalism`).

## Langkah 3: Menambahkan Komponen

Untuk menambahkan komponen baru (misalnya tombol), gunakan perintah `add`:

```bash
just_ui add button
```

Komponen tersebut akan disalin secara otomatis ke direktori komponen proyek Flutter Anda (default: `lib/components/ui/button.dart`).
