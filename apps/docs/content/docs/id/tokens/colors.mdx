Sistem warna JustUI dirancang dengan fokus utama pada keindahan visual, performa tinggi, dan kepatuhan penuh terhadap standar aksesibilitas web **WCAG 2.0 (AA)**. Token warna dipisahkan antara palet primitif mentah (raw palette) dan pemetaan semantik fungsional yang beradaptasi secara dinamis berdasarkan tema aktif dan preset yang dipilih.

## 2. Skema Warna Semantik (`JustColorScheme`)

JustUI memetakan palet primitif ke dalam skema warna semantik fungsional melalui kelas `JustColorScheme`. Pemetaan ini memastikan komponen UI menggunakan token warna yang konsisten di semua status.

### Properti Utama `JustColorScheme`

Skema warna mendefinisikan beberapa kategori warna sebagai berikut:

- **Surface Colors**: `background` (latar halaman), `card` (kontainer kartu), `elevated` (dialog/overlay mengambang), `overlay` (latar belakang modal transparan).
- **Text Colors**: `textPrimary` (kontras tinggi/judul), `textSecondary` (keterangan/badan teks), `textDisabled` (teks nonaktif), `textInverse` (teks di atas warna kontras tinggi).
- **Border Colors**: `borderDefault` (pembatas input/garis halus), `borderFocus` (border indikator fokus aktif), `borderError` (border status galat/error).
- **State Colors**: `success` (sukses/aman), `warning` (peringatan/perhatian), `error` (kesalahan/bahaya), `info` (informasi/panduan).

### Mode Terang vs Mode Gelap (Default)

Secara bawaan (`JustThemePreset.default_`), JustUI mendefinisikan skema warna semantik sebagai berikut:

## 3. Preset Visual Neobrutalism

JustUI mendukung gaya desain **Neobrutalism** (`JustThemePreset.neobrutalism`). Preset ini memaksa skema warna menggunakan kontras yang sangat tinggi dengan garis tepi hitam/putih pekat tanpa gradien atau transisi warna lembut.

- **Neobrutalism Mode Terang**: Menggunakan latar belakang krem hangat (`Color(0xFFFFFDF5)`), warna teks utama hitam pekat (`Color(0xFF000000)`), dan memaksa warna border (`borderDefault`, `borderFocus`, `borderError`) menjadi hitam pekat di setiap keadaan.
- **Neobrutalism Mode Gelap**: Menggunakan latar belakang abu-abu gelap pekat (`Color(0xFF121212)`), teks utama putih pekat (`Color(0xFFFFFFFF)`), dan memaksa seluruh border menjadi putih pekat.

## 4. Audit Aksesibilitas Kontras Warna (WCAG AA)

Keterbacaan antarmuka adalah prioritas utama. JustUI menyertakan sistem audit aksesibilitas kontras bawaan melalui ekstensi `JustColorAccessibility` pada kelas `Color`.

### Formula Rasio Kontras

Luminansi relatif (L) dihitung berdasarkan kurva warna standar RGB (diperoleh melalui method internal Flutter `Color.computeLuminance()`), menghasilkan nilai antara `0.0` (hitam pekat) dan `1.0` (putih pekat).

Formula rasio kontras WCAG 2.0 adalah:

```text
R = (L1 + 0.05) / (L2 + 0.05)
```

Di mana L1 adalah luminansi warna yang lebih terang, dan L2 adalah luminansi warna yang lebih gelap. Konstanta `0.05` ditambahkan untuk mengimbangi adaptasi mata manusia terhadap pendaran layar (_glare_).

### Metode Ekstensi `JustColorAccessibility`

Ekstensi ini menyediakan dua API utama:

1. `contrastRatioWith(Color other)`: Menghasilkan nilai rasio antara `1.0` (tidak ada kontras/warna sama) hingga `21.0` (kontras sempurna hitam dan putih).
2. `isAccessibleWith(Color other, {bool isLargeText = false})`: Memeriksa kepatuhan kontras terhadap standar WCAG AA:
   - **Teks Normal**: Membutuhkan rasio kontras minimal **4.5:1** terhadap latar belakang.
   - **Teks Besar / Komponen Visual** (seperti border input, fokus, atau lencana): Membutuhkan rasio kontras minimal **3.0:1**. Teks besar didefinisikan sebagai teks berukuran ≥ 18pt/24px (atau teks tebal ≥ 14pt/18.67px).

```dart
// Contoh penggunaan audit kontras secara manual:
final Color background = context.justColors.background;
final Color textColor = context.justColors.textSecondary;

final double ratio = textColor.contrastRatioWith(background);
final bool isAccessible = textColor.isAccessibleWith(background);

print('Rasio Kontras: $ratio (Lolos WCAG AA: $isAccessible)');
```

## 5. Penegakan Kontras Dinamis (`JustThemeData.fromSeed`)

Saat menginisialisasi tema kustom menggunakan metode generator `JustThemeData.fromSeed(Color seedColor)`, JustUI menjalankan algoritma otomatis di runtime untuk memastikan warna merek/primer yang dihasilkan tetap memenuhi kontras aksesibilitas terhadap warna latar belakang.

### Algoritma Lightness Adjustment (`colors_dynamic.dart`)

Jika warna primer asal tidak memenuhi rasio kontras minimum terhadap latar belakang:

1. **Deteksi Arah Kecerahan**: Sistem mengevaluasi tingkat kecerahan latar belakang (`bgLuminance < 0.5`). Jika latar belakang cenderung gelap, warna primer harus disesuaikan menjadi lebih terang. Jika latar belakang terang, warna primer disesuaikan menjadi lebih gelap.
2. **Binary Search (8 Iterasi)**: Menggunakan algoritma pencarian biner pada parameter _Lightness_ skala HSL warna asal. Algoritma ini mencari nilai lightness terdekat yang memenuhi target rasio kontras dengan tetap menjaga nilai _Hue_ (corak) dan _Saturation_ (kejenuhan) agar estetika warna merek tetap terjaga.
3. **Bypass Preset**: Algoritma kompensasi HSL dinamis ini secara otomatis diabaikan (_bypass_) ketika preset visual yang aktif adalah `neobrutalism`, demi menjaga estetika border hitam pekat khas neobrutalism.

## 6. Contoh Praktik Terbaik Konsumsi Warna di Flutter

Untuk menjaga performa rendering pohon widget tetap optimal saat terjadi pergantian warna (seperti toggle mode gelap), pastikan Anda mengonsumsi warna menggunakan aspek context yang tepat.

```dart
class CustomCardWidget extends StatelessWidget {
  const CustomCardWidget({super.key});

  @override
  Widget build(BuildContext context) {
    // Mendaftarkan widget HANYA pada aspek warna.
    // Widget tidak akan di-rebuild jika aspek lain (seperti spacing/typography) berubah.
    final colors = context.justColors;

    return Container(
      padding: .all(16.0),
      decoration: BoxDecoration(
        color: colors.card,
        border: Border.all(color: colors.borderDefault),
        borderRadius: const BorderRadius.all(Radius.circular(8.0)),
      ),
      child: Text(
        'Visual Primitive Audit',
        style: TextStyle(color: colors.textPrimary),
      ),
    );
  }
}
```
