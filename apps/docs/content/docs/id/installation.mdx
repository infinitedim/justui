# Instalasi

JustUI menyediakan alat baris perintah (CLI) berbasis Rust untuk menyalin komponen ke dalam proyek Flutter Anda dengan cepat.

## Langkah 1: Instalasi JustUI CLI

### Melalui Script Instalasi (Direkomendasikan)

Semua binary yang diunduh melalui script instalasi diverifikasi secara kriptografis terhadap checksum SHA-256 yang dipublikasikan sebelum proses instalasi.

```bash
# macOS / Linux
curl -fsSL https://justui.vercel.app/install.sh | sh

# Windows (PowerShell)
irm https://justui.vercel.app/install.ps1 | iex
```

### Kompilasi dari Source (Zero-Trust)

Bila Anda memilih untuk membangun langsung dari source code:

```bash
git clone https://github.com/infinitedim/justui.git
cd justui/packages/cli
cargo install --path .
```

Verifikasi hasil instalasi:

```bash
justui --version
```

## Langkah 2: Inisialisasi Proyek

Jalankan perintah berikut di direktori root proyek Flutter Anda:

```bash
justui init
```

Panduan interaktif akan membuat file konfigurasi `justui.config.yaml` dan menyiapkan file tema di `lib/core/theme/just_theme.dart`. Anda juga akan ditanya pilihan preset visual utama (`default` atau `neobrutalism`).

## Langkah 3: Menambahkan Komponen

Untuk menambahkan komponen baru (misalnya tombol), gunakan perintah `add`:

```bash
justui add button
```

Komponen beserta dependensinya akan disalin secara otomatis ke direktori komponen proyek Flutter Anda (default: `lib/widgets/button`).
