# Quick Start

Selamat datang di panduan langkah awal JustUI! Dalam waktu kurang dari 5 menit, Anda akan mempelajari cara menyiapkan sistem desain JustUI di aplikasi Flutter baru Anda, mengonfigurasi visual preset, dan menggunakan komponen pertama Anda.

## Prasyarat

Sebelum memulai, pastikan Anda telah menyelesaikan langkah-langkah di halaman [Instalasi](/docs/installation):

1. Mengaktifkan CLI tool secara global: `dart pub global activate just_ui_cli`
2. Menjalankan inisialisasi: `justui init` di root proyek Flutter Anda.

---

## Langkah 1: Setup Provider di Root Widget

JustUI menggunakan `JustThemeProvider` untuk mengelola mode tema (terang, gelap, atau sistem) dan menyebarkan data tema secara efisien menggunakan _Aspect-Based Rebuilds_.

Buka file entry point aplikasi Anda (biasanya `lib/main.dart`) dan bungkus root widget Anda dengan `JustThemeProvider`:

```dart
import 'package:flutter/widgets.dart';
import 'package:just_ui_core/just_ui_core.dart';
import 'theme/just_theme.dart'; // File tema yang dihasilkan oleh CLI

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return JustThemeProvider(
      initialThemeMode: ThemeMode.system,
      // Gunakan tema default atau kustomisasi sesuai kebutuhan Anda
      lightTheme: JustThemeData.light,
      darkTheme: JustThemeData.dark,
      child: const HomeScreen(),
    );
  }
}
```

> **Catatan**: Jika proyek Anda masih menggunakan MaterialApp untuk navigasi atau utilitas bawaan Flutter, Anda dapat mengintegrasikan data tema JustUI ke dalam Material `ThemeData` dengan mudah menggunakan ekstensi `.toThemeData()`:
>
> ```dart
> MaterialApp(
>   theme: JustThemeData.light.toThemeData(),
>   darkTheme: JustThemeData.dark.toThemeData(),
>   themeMode: ThemeMode.system,
>   home: const HomeScreen(),
> )
> ```

## Langkah 2: Menggunakan Visual Preset

JustUI mendukung dua preset visual utama yang dapat dikonfigurasi saat inisialisasi atau diubah secara dinamis pada `JustThemeData`:

1. **Default Preset (`JustThemePreset.default_`)**: Desain modern, bersih, dengan sudut melengkung halus dan bayangan lembut.
2. **Neobrutalism Preset (`JustThemePreset.neobrutalism`)**: Estetika berani dengan border tebal (2.5px), sudut tegas, bayangan solid dengan offset datar, dan kontras warna yang tinggi (hitam pekat di mode terang, putih pekat di mode gelap).

Contoh inisialisasi menggunakan preset **Neobrutalism**:

```dart
import 'package:flutter/widgets.dart';
import 'package:just_ui_core/just_ui_core.dart';

// Di dalam main.dart atau file konfigurasi tema Anda
final neobrutalismTheme = JustThemeData(
  colors: JustColors.neobrutalismLight(),
  shadows: const NeobrutalismShadowScheme(),
  preset: JustThemePreset.neobrutalism, // Menggunakan preset neobrutalism
);
```

## Langkah 3: Menambahkan dan Menggunakan Komponen Pertama

Mari tambahkan komponen tombol (`JustButton`) ke proyek Anda menggunakan CLI:

```bash
justui add button
```

CLI akan mengunduh dan menyalin kode sumber `JustButton` ke dalam folder komponen Anda (misalnya `lib/components/ui/button.dart`).

Sekarang, Anda dapat langsung mengimpor dan menggunakan tombol tersebut di widget halaman Anda.

### Contoh Penggunaan `JustButton`

Gunakan gaya penulisan _Dart Dot Shorthand_ untuk parameter bawaan Flutter (seperti `.symmetric` atau `.all`) untuk menyelaraskan dengan gaya penulisan kode JustUI:

```dart
import 'package:flutter/material.dart' show Icons;
import 'package:flutter/widgets.dart';
import 'package:just_ui_core/just_ui_core.dart';
import 'components/ui/button.dart'; // Sesuaikan dengan jalur impor Anda

class HomeScreen extends StatelessWidget {
  const HomeScreen({super.key});

  @override
  Widget build(BuildContext context) {
    // Mengakses token warna, spacing, dan radius dari context
    final colors = context.justColors;
    final spacing = context.justSpacing;

    return Container(
      color: colors.background,
      padding: .all(spacing.lg), // Dart Dot Shorthand
      child: Center(
        child: Column(
          mainAxisAlignment: .center,
          children: [
            // 1. Tombol Utama (Primary)
            JustButton(
              label: 'Mulai Sekarang',
              onPressed: () {
                print('Tombol ditekan!');
              },
            ),
            const SizedBox(height: 16),

            // 2. Tombol Loading dengan Ikon Depan
            JustButton.secondary(
              label: 'Mengunduh Data',
              leading: const Icon(Icons.download),
              isLoading: true,
              onPressed: () {},
            ),
          ],
        ),
      ),
    );
  }
}
```

### Aturan Penting Konsumsi Tema:

- **Gunakan aspek spesifik** di dalam metode `build`: `context.justColors` untuk warna, `context.justSpacing` untuk jarak, dan `context.justTypo` untuk tipografi. Ini memastikan widget Anda hanya me-rebuild saat aspek yang digunakan mengalami perubahan.
- **Gunakan API non-registering** di dalam callback interaksi (seperti `onPressed`): gunakan `context.readTheme()` alih-alih getter aktif untuk menghindari pemanggilan rebuild pohon widget yang tidak perlu.
