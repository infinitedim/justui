# Separator

`JustSeparator` adalah komponen garis pembatas (_divider_) dekoratif yang memisahkan konten dalam tata letak aplikasi. Komponen ini mendukung penyisipan label teks opsional di bagian tengah garis pembatas, ketebalan kustom, dan pergantian arah orientasi (horizontal ke vertikal) secara dinamis/responsif berdasarkan lebar layar.

## Usage

### Basic

Berikut adalah contoh penggunaan dasar `JustSeparator` untuk pembatas horizontal sederhana.

```dart
import 'package:flutter/material.dart';
import 'package:just_ui_core/just_ui_core.dart';
import 'package:just_ui_tokens/just_ui_tokens.dart';

class BasicSeparatorExample extends StatelessWidget {
  const BasicSeparatorExample({super.key});

  @override
  Widget build(BuildContext context) {
    return Column(
      children: const [
        Text('Bagian Atas'),
        JustSeparator(),
        Text('Bagian Bawah'),
      ],
    );
  }
}
```

### Advanced

Contoh penggunaan lanjutan dengan label teks tengah, ketebalan kustom, indentasi pangkal dan ujung, serta responsivitas orientasi.

```dart
import 'package:flutter/material.dart';
import 'package:just_ui_core/just_ui_core.dart';
import 'package:just_ui_tokens/just_ui_tokens.dart';

class AdvancedSeparatorExample extends StatelessWidget {
  const AdvancedSeparatorExample({super.key});

  @override
  Widget build(BuildContext context) {
    return Column(
      children: [
        const Text('Daftar dengan Akun Sosial'),
        const SizedBox(height: 16),
        JustSeparator(
          direction: null, // Responsif (horizontal pada mobile, vertikal pada desktop)
          breakpoint: 640.0,
          thickness: 1.5,
          indent: 16.0,
          endIndent: 16.0,
          label: 'ATAU',
          labelStyle: context.justTypo.caption.copyWith(
            color: context.justColors.textMuted,
            fontWeight: FontWeight.bold,
          ),
        ),
        const SizedBox(height: 16),
        Row(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            JustButton(
              label: 'Google',
              onPressed: () {},
            ),
            const SizedBox(width: 12),
            JustButton(
              label: 'GitHub',
              onPressed: () {},
            ),
          ],
        ),
      ],
    );
  }
}
```

## API Reference (Props)

### JustSeparator

| Properti     | Tipe Data    | Nilai Bawaan      | Deskripsi                                                                                                                              |
| ------------ | ------------ | ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `direction`  | `Axis?`      | `Axis.horizontal` | Arah pembatas (horizontal atau vertikal). Jika disetel `null`, separator akan bersikap responsif terhadap lebar layar secara otomatis. |
| `breakpoint` | `double`     | `640.0`           | Batas lebar layar (dalam piksel) untuk memicu pembalikan orientasi dari horizontal ke vertikal jika `direction` disetel responsif.     |
| `thickness`  | `double`     | `1.0`             | Ukuran ketebalan fisik garis pembatas.                                                                                                 |
| `color`      | `Color?`     | `null`            | Warna garis pembatas (default mengikuti warna batas tema `colors.border`).                                                             |
| `indent`     | `double`     | `0.0`             | Jarak spasi kosong pemotong garis di bagian pangkal/awal.                                                                              |
| `endIndent`  | `double`     | `0.0`             | Jarak spasi kosong pemotong garis di bagian ujung/akhir.                                                                               |
| `label`      | `String?`    | `null`            | Label teks opsional yang ditempatkan di tengah-bagi garis pembatas (misal: "ATAU" di sela form).                                       |
| `labelStyle` | `TextStyle?` | `null`            | Gaya visual teks label di bagian tengah.                                                                                               |

## Theming & Accessibility

### Penjelasan Kustomisasi Preset & Style

- **Default Style**: Garis pembatas memiliki ketebalan bawaan `1.0` dan warna abu-abu netral tipis yang menyatu dengan latar belakang kontainer utama.
- **Neobrutalism Style**: Ketebalan default dipaksa menjadi `2.5` dengan warna border solid hitam pekat/putih pekat (`colors.textPrimary`). Teks label di tengah dibungkus dengan kotak bergaris tepi kaku dan warna latar belakang solid yang kontras untuk mempertegas pembagian konten secara jelas.

### Pemenuhan Standar WCAG AA

- **Peran Semantik**: Secara bawaan, garis pembatas ditandai dengan peran semantik dekoratif (`excludeSemantics: true`) agar pembaca layar (_screen reader_) melewatkannya secara otomatis dan tidak mengganggu alur pembacaan konten utama oleh pengguna disabilitas.
- **Kontras Warna**: Jika `label` teks disuplai di bagian tengah, warna teks dan garis dijamin lolos uji kontras minimum $\ge$ 4.5:1 terhadap latar belakang sekitarnya untuk keterbacaan optimal.
