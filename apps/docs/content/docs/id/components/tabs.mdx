# Tabs

`JustTabs` adalah komponen yang digunakan untuk membagi konten ke dalam beberapa tampilan panel navigasi yang saling terhubung. Komponen ini dirancang untuk memaksimalkan performa rendering di Flutter dengan menerapkan teknik pemuatan malas (_lazy loading_) dan _caching_ halaman yang aktif dikunjungi, serta transisi indikator geser yang halus.

## Usage

### Basic

Berikut adalah contoh penggunaan dasar `JustTabs` untuk membuat tab navigasi sederhana.

```dart
import 'package:flutter/material.dart';
import 'package:your_app/core/just_ui_core.dart';

class BasicTabsExample extends StatelessWidget {
  const BasicTabsExample({super.key});

  @override
  Widget build(BuildContext context) {
    return JustTabs(
      tabs: [
        JustTab(
          label: 'Profil',
          icon: const Icon(Icons.person),
          content: const Center(child: Text('Konten Profil Pengguna')),
        ),
        JustTab(
          label: 'Pengaturan',
          icon: const Icon(Icons.settings),
          content: const Center(child: Text('Konten Pengaturan')),
        ),
      ],
    );
  }
}
```

### Advanced

Berikut adalah contoh penggunaan lanjutan menggunakan varian `pill`, judul tab yang dapat digeser secara horizontal (_scrollable_), penambahan _badge_, dan tab yang dinonaktifkan.

```dart
import 'package:flutter/material.dart';
import 'package:your_app/core/just_ui_core.dart';

class AdvancedTabsExample extends StatefulWidget {
  const AdvancedTabsExample({super.key});

  @override
  State<AdvancedTabsExample> createState() => _AdvancedTabsExampleState();
}

class _AdvancedTabsExampleState extends State<AdvancedTabsExample> {
  late final JustTabController _tabController;

  @override
  void initState() {
    super.initState();
    _tabController = JustTabController(length: 4, initialIndex: 0);
  }

  @override
  void dispose() {
    _tabController.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return JustTabs(
      controller: _tabController,
      variant: JustTabVariant.pill,
      isScrollable: true,
      tabs: [
        JustTab(
          label: 'Akun',
          icon: const Icon(Icons.account_circle),
          content: const AccountSettingsView(),
        ),
        JustTab(
          label: 'Keamanan',
          icon: const Icon(Icons.security),
          content: const SecuritySettingsView(),
          badge: const JustBadge.dot(color: JustBadgeColor.error),
        ),
        JustTab(
          label: 'Notifikasi',
          icon: const Icon(Icons.notifications),
          content: const NotificationSettingsView(),
        ),
        JustTab(
          label: 'Riwayat Transaksi',
          icon: const Icon(Icons.history),
          content: const TransactionHistoryView(),
          enabled: false, // Tab dinonaktifkan secara visual dan fungsional
        ),
      ],
    );
  }
}
```

## API Reference (Props)

### JustTabs

| Properti         | Tipe Data            | Nilai Bawaan          | Deskripsi                                                                                                                                                           |
| ---------------- | -------------------- | --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tabs`           | `List<JustTab>`      | _Wajib_               | Rangkaian objek tab yang berisi label, ikon, konten, dan status masing-masing panel.                                                                                |
| `variant`        | `JustTabVariant`     | `JustTabVariant.line` | Gaya visual tab: `.line` (garis bawah aktif), `.enclosed` (kontainer kartu bersudut), `.pill` (pil solid transparan), atau `.vertical` (panel tab di kiri halaman). |
| `controller`     | `JustTabController?` | `null`                | Pengontrol eksternal untuk mengelola sinkronisasi indeks aktif secara terprogram.                                                                                   |
| `isScrollable`   | `bool`               | `false`               | Menentukan apakah bilah judul tab dapat digeser secara horizontal jika teks judul sangat panjang.                                                                   |
| `style`          | `JustTabsStyle?`     | `null`                | Kustomisasi visual per instance untuk warna, tipografi, padding, indikator, dan garis bawah tab bar.                                                                |
| `semanticsLabel` | `String?`            | `null`                | Label aksesibilitas yang dibacakan untuk kontainer tablist (`SemanticsRole.tabBar`).                                                                                |
| `showContent`    | `bool`               | `true`                | Menentukan apakah halaman konten tab ikut dirender di bawah atau di samping tab bar.                                                                                |

### JustTab

| Properti  | Tipe Data | Nilai Bawaan | Deskripsi                                                                      |
| --------- | --------- | ------------ | ------------------------------------------------------------------------------ |
| `label`   | `String`  | _Wajib_      | Teks judul yang ditampilkan pada bilah tombol tab.                             |
| `content` | `Widget`  | _Wajib_      | Widget isi halaman yang ditampilkan saat tab aktif dipilih.                    |
| `icon`    | `Widget?` | `null`       | Widget ikon opsional di samping label teks.                                    |
| `badge`   | `Widget?` | `null`       | Widget lencana opsional (seperti `JustBadge.dot`) untuk notifikasi status tab. |
| `enabled` | `bool`    | `true`       | Menentukan apakah tab dapat diklik dan diaktifkan.                             |

### JustTabsStyle

Kamu bisa menggunakan `JustTabsStyle` untuk mengatur ulang padding, warna, tipografi, dimensi indikator, radius kontainer, dan garis pembatas bawah per instance:

| Properti            | Tipe Data | Nilai Bawaan | Deskripsi                                                                                                                |
| ------------------- | --------- | ------------ | ------------------------------------------------------------------------------------------------------------------------ |
| `borderBottomColor` | `Color?`  | `null`       | Warna garis bawah tipis (hairline) pada kontainer tab bar (misalnya pada `JustTabVariant.line`).                         |
| `borderBottomWidth` | `double?` | `null`       | Ketebalan garis bawah kontainer tab bar (bawaannya mengikuti `presetTokens.borderWidth` saat `borderBottomColor` diisi). |

## Theming & Accessibility

### Penjelasan Kustomisasi Preset & Style

- **Default Preset**: Menggunakan efek transisi garis bawah meluncur (`JustTabVariant.line`) yang halus. Pada varian `.enclosed` dan `.pill`, perpindahan aktif menggunakan transisi warna latar belakang yang diatur oleh `JustDuration.normal` dan `JustCurves.default_`. Kamu bisa menambahkan garis bawah kustom pada tab `.line` lewat `JustTabsStyle.borderBottomColor` dan `JustTabsStyle.borderBottomWidth`.
- **Neobrutalism Preset**: Di bawah preset neobrutalism, garis tepi tab pada varian `.enclosed` dan `.pill` menggunakan warna solid `colors.textPrimary` dengan ketebalan `presetTokens.borderWidth`. Profil gerak berjalan lebih cepat untuk transisi yang tegas tanpa jitter visual.

### Pemenuhan Standar WCAG AA

- **Pemuatan Malas (Lazy Loading) & Caching**: Untuk menjaga performa rendering di perangkat berspesifikasi rendah, `JustTabs` melacak indeks yang pernah dibuka melalui `Set<int> _visitedIndices`. Halaman konten yang belum dibuka mengembalikan `SizedBox.shrink()`, lalu setelah dibuka akan dipertahankan di memori menggunakan `AutomaticKeepAliveClientMixin` agar perpindahan berikutnya tetap menjaga state.
- **Perhitungan Geometri Indikator**: Posisi indikator aktif diukur secara dinamis menggunakan `GlobalKey` dan diinterpolasi secara linear antar posisi tab untuk transisi geser yang akurat.
- **WAI-ARIA Roving Tabindex & Navigasi Keyboard**: Tablist menyediakan 1 perhentian `Tab` dengan mengatur `skipTraversal: true` pada tab yang tidak aktif. Tombol `ArrowLeft`/`ArrowRight` (atau `ArrowUp`/`ArrowDown` pada `JustTabVariant.vertical`) serta `Home`/`End` memindahkan fokus keyboard sekaligus pilihan aktif sambil melewati tab nonaktif (`enabled: false`). Penahanan tombol (_key repeat_ lewat `KeyRepeatEvent`) didukung, dan `Enter`/`Space` mengaktifkan tab yang sedang fokus.
- **FocusIndicator, Semantik & Reduced Motion**: Tab yang menerima fokus keyboard menampilkan `FocusIndicator` yang jelas. Kontainer tab bar menggunakan `SemanticsRole.tabBar` (dengan `semanticsLabel` opsional), sedangkan tiap item menggunakan `SemanticsRole.tab` dengan status `selected`, `enabled`, dan `excludeSemantics: true`. Rasio kontras teks aktif memenuhi >= 4.5:1, dan saat _reduced motion_ aktif, `animations.resolve(context)` menjadi `Duration.zero` sehingga pergantian halaman langsung melompat lewat `jumpToPage`.
