# Tabs

`JustTabs` adalah komponen yang digunakan untuk membagi konten ke dalam beberapa tampilan panel navigasi yang saling terhubung. Komponen ini dirancang untuk memaksimalkan performa rendering di Flutter dengan menerapkan teknik pemuatan malas (_lazy loading_) dan _caching_ halaman yang aktif dikunjungi, serta transisi indikator geser yang halus.

## Usage

### Basic

Berikut adalah contoh penggunaan dasar `JustTabs` untuk membuat tab navigasi sederhana.

```dart
import 'package:flutter/material.dart';
import 'package:just_ui_core/just_ui_core.dart';
import 'package:just_ui_tokens/just_ui_tokens.dart';

class BasicTabsExample extends StatelessWidget {
  const BasicTabsExample({super.key});

  @override
  Widget build(BuildContext context) {
    return JustTabs(
      tabs: [
        JustTab(
          label: 'Profil',
          icon: const Icon(Icons.person),
          content: const Center(child: Text('Konten Profil Pengguna')),
        ),
        JustTab(
          label: 'Pengaturan',
          icon: const Icon(Icons.settings),
          content: const Center(child: Text('Konten Pengaturan')),
        ),
      ],
    );
  }
}
```

### Advanced

Berikut adalah contoh penggunaan lanjutan menggunakan varian `pill`, judul tab yang dapat digeser secara horizontal (_scrollable_), penambahan _badge_, dan tab yang dinonaktifkan.

```dart
import 'package:flutter/material.dart';
import 'package:just_ui_core/just_ui_core.dart';
import 'package:just_ui_tokens/just_ui_tokens.dart';

class AdvancedTabsExample extends StatefulWidget {
  const AdvancedTabsExample({super.key});

  @override
  State<AdvancedTabsExample> createState() => _AdvancedTabsExampleState();
}

class _AdvancedTabsExampleState extends State<AdvancedTabsExample> {
  late final JustTabController _tabController;

  @override
  void initState() {
    super.initState();
    _tabController = JustTabController(initialIndex: 0);
  }

  @override
  void dispose() {
    _tabController.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return JustTabs(
      controller: _tabController,
      variant: JustTabVariant.pill,
      isScrollable: true,
      tabs: [
        JustTab(
          label: 'Akun',
          icon: const Icon(Icons.account_circle),
          content: const AccountSettingsView(),
        ),
        JustTab(
          label: 'Keamanan',
          icon: const Icon(Icons.security),
          content: const SecuritySettingsView(),
          badge: const JustBadge.dot(color: JustBadgeColor.error),
        ),
        JustTab(
          label: 'Notifikasi',
          icon: const Icon(Icons.notifications),
          content: const NotificationSettingsView(),
        ),
        JustTab(
          label: 'Riwayat Transaksi',
          icon: const Icon(Icons.history),
          content: const TransactionHistoryView(),
          enabled: false, // Tab dinonaktifkan secara visual dan fungsional
        ),
      ],
    );
  }
}
```

## API Reference (Props)

### JustTabs

| Properti       | Tipe Data            | Nilai Bawaan          | Deskripsi                                                                                                                                                           |
| -------------- | -------------------- | --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tabs`         | `List<JustTab>`      | _Wajib_               | Rangkaian objek tab yang berisi label, ikon, konten, dan status masing-masing panel.                                                                                |
| `variant`      | `JustTabVariant`     | `JustTabVariant.line` | Gaya visual tab: `.line` (garis bawah aktif), `.enclosed` (kontainer kartu bersudut), `.pill` (pil solid transparan), atau `.vertical` (panel tab di kiri halaman). |
| `controller`   | `JustTabController?` | `null`                | Pengontrol eksternal untuk mengelola sinkronisasi indeks aktif secara terprogram.                                                                                   |
| `isScrollable` | `bool`               | `false`               | Menentukan apakah bilah judul tab dapat digeser secara horizontal jika teks judul sangat panjang.                                                                   |

### JustTab

| Properti  | Tipe Data | Nilai Bawaan | Deskripsi                                                                      |
| --------- | --------- | ------------ | ------------------------------------------------------------------------------ |
| `label`   | `String`  | _Wajib_      | Teks judul yang ditampilkan pada bilah tombol tab.                             |
| `content` | `Widget`  | _Wajib_      | Widget isi halaman yang ditampilkan saat tab aktif dipilih.                    |
| `icon`    | `Widget?` | `null`       | Widget ikon opsional di samping label teks.                                    |
| `badge`   | `Widget?` | `null`       | Widget lencana opsional (seperti `JustBadge.dot`) untuk notifikasi status tab. |
| `enabled` | `bool`    | `true`       | Menentukan apakah tab dapat diklik dan diaktifkan.                             |

## Theming & Accessibility

### Penjelasan Kustomisasi Preset & Style

- **Default Preset**: Menggunakan efek transisi garis bawah meluncur (`JustTabVariant.line`) yang halus. Pada varian `.enclosed` dan `.pill`, perpindahan aktif menggunakan transisi memudar gradasi warna latar belakang yang diatur oleh `JustDuration.normal` (250ms) dan `JustCurves.default_`.
- **Neobrutalism Preset**: Di bawah preset neobrutalism, garis tepi tab dipaksa menggunakan warna solid hitam pekat/putih pekat (`colors.textPrimary`) dengan ketebalan border `2.5`. Durasi animasi dipercepat secara instan (`JustDuration.instant`) untuk menghindari jitter visual, dan warna border tidak bertransisi ke warna primer/tinted (tetap hitam pekat/putih pekat).

### Pemenuhan Standar WCAG AA

- **Pemuatan Malas (Lazy Loading) & Caching**: Untuk menjaga performa rendering di perangkat dengan spesifikasi rendah, `JustTabs` mengimplementasikan `Set<int> _visitedIndices`. Halaman konten tab yang belum pernah dikunjungi oleh pengguna sama sekali tidak akan diinisialisasi dalam widget tree (mengembalikan `SizedBox.shrink()`). Setelah tab dibuka pertama kali, ia disimpan dalam memori menggunakan `AutomaticKeepAliveClientMixin` agar transisi antar tab berikutnya berjalan instan tanpa memicu pembuatan ulang status halaman (_no loss of state_).
- **Perhitungan Geometri Indikator**: Posisi garis indikator aktif dihitung secara dinamis menggunakan kunci global (`GlobalKey`). Rentang pergeseran indikator diinterpolasi secara linear berdasarkan data koordinat target untuk menciptakan efek transisi meluncur yang akurat.
- **Aksesibilitas Kontras & Navigasi**: Rasio kontras teks aktif terhadap background dijamin $\ge$ 4.5:1. Tab yang dinonaktifkan (`enabled: false`) memiliki visual semi-transparan dan diabaikan dari daftar navigasi keyboard. Setiap tombol tab dibungkus dengan semantik terpilih (`Semantics(selected: true/false)`) agar dapat diidentifikasi oleh pembaca layar (_screen reader_).
