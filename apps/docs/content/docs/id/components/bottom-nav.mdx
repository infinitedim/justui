# Bottom Navigation

`JustBottomNav` adalah komponen navigasi utama pada antarmuka perangkat seluler yang ditempatkan di bagian bawah layar. Komponen ini dirancang untuk mempermudah perpindahan antar halaman utama aplikasi dengan mendukung minimal 3 hingga maksimal 5 item navigasi, serta menawarkan varian gaya tetap (_fixed_), berpindah dinamis (_shifting_), dan mengambang (_floating_).

## Usage

### Basic

Contoh penggunaan dasar `JustBottomNav` dengan gaya lebar tetap bawaan (_fixed_) untuk 3 menu utama.

```dart
import 'package:flutter/material.dart';
import 'package:your_app/core/just_ui_core.dart';

class BasicBottomNavExample extends StatefulWidget {
  const BasicBottomNavExample({super.key});

  @override
  State<BasicBottomNavExample> createState() => _BasicBottomNavExampleState();
}

class _BasicBottomNavExampleState extends State<BasicBottomNavExample> {
  int _currentIndex = 0;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      bottomNavigationBar: JustBottomNav(
        selectedIndex: _currentIndex,
        onItemSelected: (index) {
          setState(() {
            _currentIndex = index;
          });
        },
        items: const [
          JustBottomNavItem(
            label: 'Beranda',
            icon: Icon(Icons.home_outlined),
            activeIcon: Icon(Icons.home),
          ),
          JustBottomNavItem(
            label: 'Cari',
            icon: Icon(Icons.search),
          ),
          JustBottomNavItem(
            label: 'Profil',
            icon: Icon(Icons.person_outline),
            activeIcon: Icon(Icons.person),
          ),
        ],
      ),
    );
  }
}
```

### Advanced

Contoh penggunaan lanjutan menggunakan varian mengambang (_floating_), umpan balik getar (_haptic feedback_), dan perataan ikon.

```dart
import 'package:flutter/material.dart';
import 'package:flutter/services.dart';
import 'package:your_app/core/just_ui_core.dart';

class AdvancedBottomNavExample extends StatefulWidget {
  const AdvancedBottomNavExample({super.key});

  @override
  State<AdvancedBottomNavExample> createState() => _AdvancedBottomNavExampleState();
}

class _AdvancedBottomNavExampleState extends State<AdvancedBottomNavExample> {
  int _currentIndex = 0;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      bottomNavigationBar: Padding(
        padding: const EdgeInsets.all(16.0),
        child: JustBottomNav(
          selectedIndex: _currentIndex,
          variant: JustBottomNavVariant.floating,
          showLabels: true,
          onItemSelected: (index) {
            HapticFeedback.lightImpact(); // Memberikan getaran haptic ringan
            setState(() {
              _currentIndex = index;
            });
          },
          items: const [
            JustBottomNavItem(
              label: 'Beranda',
              icon: Icon(Icons.home_outlined),
              activeIcon: Icon(Icons.home),
            ),
            JustBottomNavItem(
              label: 'Pesan',
              icon: Icon(Icons.chat_bubble_outline),
              activeIcon: Icon(Icons.chat_bubble),
            ),
            JustBottomNavItem(
              label: 'Keranjang',
              icon: Icon(Icons.shopping_cart_outlined),
              activeIcon: Icon(Icons.shopping_cart),
            ),
            JustBottomNavItem(
              label: 'Akun',
              icon: Icon(Icons.account_circle_outlined),
              activeIcon: Icon(Icons.account_circle),
            ),
          ],
        ),
      ),
    );
  }
}
```

## API Reference (Props)

### JustBottomNav

| Properti         | Tipe Data                 | Nilai Bawaan                 | Deskripsi                                                                                                                                                                                                        |
| ---------------- | ------------------------- | ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `items`          | `List<JustBottomNavItem>` | _Wajib_                      | Rangkaian menu tujuan navigasi bawah (harus berjumlah minimal 3 dan maksimal 5 item).                                                                                                                            |
| `selectedIndex`  | `int`                     | `0`                          | Indeks item navigasi yang aktif terpilih saat ini.                                                                                                                                                               |
| `onItemSelected` | `ValueChanged<int>?`      | `null`                       | Callback yang terpicu ketika pengguna mengetuk salah satu item menu.                                                                                                                                             |
| `variant`        | `JustBottomNavVariant`    | `JustBottomNavVariant.fixed` | Gaya visual navigasi bawah: `.fixed` (lebar tetap), `.shifting` (efek transisi melebar saat terpilih dan menyembunyikan teks tidak aktif), atau `.floating` (mengambang bebas berbayangan lembut di atas layar). |
| `showLabels`     | `bool`                    | `true`                       | Menentukan apakah teks label di bawah ikon ditampilkan secara visual.                                                                                                                                            |
| `style`          | `JustBottomNavStyle?`     | `null`                       | Kustomisasi tampilan per instance untuk tinggi, padding, warna, border, bilah indikator aktif, tipografi, dan transisi.                                                                                          |
| `semanticsLabel` | `String?`                 | `null`                       | Label aksesibilitas opsional yang dibacakan untuk kontainer navigasi bawah.                                                                                                                                      |

### JustBottomNavItem

| Properti     | Tipe Data | Nilai Bawaan | Deskripsi                                                                |
| ------------ | --------- | ------------ | ------------------------------------------------------------------------ |
| `label`      | `String`  | _Wajib_      | Teks judul menu navigasi.                                                |
| `icon`       | `Widget`  | _Wajib_      | Ikon yang ditampilkan saat menu dalam keadaan tidak aktif.               |
| `activeIcon` | `Widget?` | `null`       | Ikon alternatif yang ditampilkan saat menu dalam keadaan aktif terpilih. |

### JustBottomNavStyle

Kamu bisa menyesuaikan dimensi bilah, warna, tipografi, dan indikator aktif per instance lewat `JustBottomNavStyle`, termasuk opsi berikut:

| Properti               | Tipe Data | Nilai Bawaan | Deskripsi                                                                                                                                       |
| ---------------------- | --------- | ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `borderColor`          | `Color?`  | `null`       | Warna border kustom untuk kontainer bilah navigasi (bawaannya `colors.textPrimary` pada Neobrutalism atau `colors.borderDefault` pada Default). |
| `activeIndicatorColor` | `Color?`  | `null`       | Warna kustom untuk bilah indikator aktif ringkas di bawah item terpilih (bawaannya mengikuti `activeColor`).                                    |
| `showActiveIndicator`  | `bool?`   | `null`       | Menentukan apakah bilah indikator aktif ringkas ditampilkan di bawah item terpilih (bawaannya `false`).                                         |

## Theming & Accessibility

### Penjelasan Kustomisasi Preset & Style

- **Default Style**: Menggunakan `colors.elevated` sebagai latar belakang bilah, garis pembatas atas `colors.borderDefault` (atau bingkai pil `BorderRadius.all(radius.full)` pada `.floating`), serta bilah indikator aktif membulat opsional lewat `JustBottomNavStyle.showActiveIndicator` dan `activeIndicatorColor`.
- **Neobrutalism Style**: Menampilkan border tegas `colors.textPrimary` (`presetTokens.borderWidth`), sudut tajam `BorderRadius.zero` di seluruh bilah (termasuk `.floating`), indikator fokus, dan bilah indikator aktif, ditambah bayangan offset solid pada `.floating`. Kamu bisa menimpa warna border menggunakan `JustBottomNavStyle.borderColor`.

### Pemenuhan Standar WCAG AA

- **Batasan Jumlah Item (Area Sentuh)**: Komponen ini memberlakukan asersi ketat pada parameter `items` agar jumlah menu berada di kisaran `3` hingga `5`, menjaga pembagian lebar yang seimbang serta area sentuh minimal 48x48 piksel di layar seluler.
- **FocusIndicator & Semantik Label Tunggal**: Setiap item menampilkan `FocusIndicator` saat fokus lewat keyboard dan membungkus isinya dalam `Semantics(label: item.label, selected: isSelected, button: true, excludeSemantics: true)` agar pembaca layar membacakan satu label bersih tanpa duplikasi node teks anak. Kontainer utamanya menggunakan `Semantics(container: true, explicitChildNodes: true, label: semanticsLabel)`. Rasio kontras teks dan ikon aktif memenuhi >= 4.5:1.
- **Dukungan Reduced Motion**: Menghormati `MediaQuery.disableAnimationsOf(context)` dan `animations.resolve(context)` dengan memangkas durasi transisi ikon, label, flex shifting, dan indikator aktif menjadi `Duration.zero` saat _reduced motion_ aktif.
