# Slider

`JustSlider` adalah komponen input geser kustom berkinerja tinggi yang dibuat tanpa menggunakan wrapper komponen bawaan Material Design. Komponen ini sepenuhnya dibangun menggunakan `GestureDetector` dan `LayoutBuilder` untuk memberikan kontrol penuh terhadap interaksi dan rendering. `JustSlider` mendukung pilihan nilai tunggal (single) maupun pilihan rentang nilai (range) dalam satu widget, serta mendukung preset visual **Default** dan **Neobrutalism** secara bawaan.

---

## Deskripsi

- **`JustSlider`**: Komponen slider standar untuk memilih satu nilai tunggal.
- **`JustSlider.range`**: Konstruktor bernama (_named constructor_) untuk memilih rentang nilai antara titik mulai (_start_) dan akhir (_end_) menggunakan dua penunjuk (_thumb_).
- **`JustRangeValues`**: Kelas data (_data class_) imutabel untuk menampung nilai awal (`start`) dan akhir (`end`) pada mode rentang. Constructor: `JustRangeValues(double start, double end)` dengan asersi `start <= end`.

---

## Usage

### Basic Usage

Contoh penggunaan dasar `JustSlider` untuk memilih satu nilai numerik.

```dart
import 'package:flutter/widgets.dart';
import 'package:just_ui_core/just_ui_core.dart';

class SliderBasicExample extends StatefulWidget {
  const SliderBasicExample({super.key});

  @override
  State<SliderBasicExample> createState() => _SliderBasicExampleState();
}

class _SliderBasicExampleState extends State<SliderBasicExample> {
  double _value = 0.5;

  @override
  Widget build(BuildContext context) {
    return JustSlider(
      value: _value,
      min: 0.0,
      max: 1.0,
      onChanged: (newValue) {
        setState(() {
          _value = newValue;
        });
      },
    );
  }
}
```

### Range Usage

Contoh penggunaan `JustSlider.range` untuk memilih rentang nilai menggunakan dua _thumb_.

```dart
import 'package:flutter/widgets.dart';
import 'package:just_ui_core/just_ui_core.dart';

class SliderRangeExample extends StatefulWidget {
  const SliderRangeExample({super.key});

  @override
  State<SliderRangeExample> createState() => _SliderRangeExampleState();
}

class _SliderRangeExampleState extends State<SliderRangeExample> {
  JustRangeValues _range = const JustRangeValues(0.2, 0.8);

  @override
  Widget build(BuildContext context) {
    return JustSlider.range(
      rangeValues: _range,
      min: 0.0,
      max: 1.0,
      onRangeChanged: (newRange) {
        setState(() {
          _range = newRange;
        });
      },
    );
  }
}
```

### Advanced Usage

Contoh penggunaan tingkat lanjut dengan menambahkan pembagi diskrit (`divisions`), indikator nilai melayang (`showTooltip`), serta konfigurasi tema global melalui `JustSliderTheme`.

```dart
import 'package:flutter/material.dart';
import 'package:just_ui_core/just_ui_core.dart';

class SliderAdvancedExample extends StatefulWidget {
  const SliderAdvancedExample({super.key});

  @override
  State<SliderAdvancedExample> createState() => _SliderAdvancedExampleState();
}

class _SliderAdvancedExampleState extends State<SliderAdvancedExample> {
  double _value = 20.0;

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      theme: ThemeData(
        extensions: const [
          JustSliderTheme(
            enableHaptic: true,
            style: JustSliderStyle(
              trackHeight: 8.0,
              thumbSize: 24.0,
            ),
          ),
        ],
      ),
      home: Center(
        child: JustSlider(
          value: _value,
          min: 0.0,
          max: 100.0,
          divisions: 10,
          showTooltip: true,
          onChanged: (newValue) {
            setState(() {
              _value = newValue;
            });
          },
        ),
      ),
    );
  }
}
```

## Theming & Accessibility

### Visual Presets

`JustSlider` menyesuaikan tampilannya secara otomatis berdasarkan preset tema yang aktif pada `JustThemeData`:

- **Default Preset**:
  - Track memiliki sudut membulat penuh (`radius.full`).
  - _Thumb_ berbentuk lingkaran dengan efek bayangan halus (_soft shadow_).
  - Menggunakan animasi pembesaran skala (_scale-up_) yang mulus saat _thumb_ ditekan atau digeser.
- **Neobrutalism Preset**:
  - Track berbentuk persegi dengan sudut sedikit melengkung (`radius.xs`) dan dikelilingi garis tepi hitam pekat setebal `2.5px`.
  - _Thumb_ berbentuk kotak persegi tebal dengan garis tepi hitam pekat setebal `2.5px` dan bayangan solid tanpa blur bergeser `(2.5, 2.5)`.
  - Ketika ditekan, bayangan solid akan runtuh (_collapse_) menjadi nol dan _thumb_ mengalami translasi pergeseran sejauh `(2.5, 2.5)` secara visual.

### Haptic Feedback

Sistem feedback haptik diatur secara bertingkat berdasarkan prioritas berikut:
`widget.enableHaptic` (prioritas tertinggi) → `JustSliderTheme.enableHaptic` → `isNeobrutalism` (default bernilai `true` pada tema neobrutalism).

Feedback haptik dipicu pada kondisi berikut:

1. Ketika pengguna pertama kali menekan atau mulai menggeser _thumb_ (`onPanStart`).
2. Ketika penunjuk mengunci (_snap_) ke titik pembagi baru (jika properti `divisions` aktif).
3. Ketika geseran mencapai batas maksimum (`max`) atau minimum (`min`) pada mode kontinu.

### Accessibility (WCAG AA Compliance)

1. **Touch Target Size**: Tinggi area widget selalu diatur sebesar `48.0px` untuk memenuhi standar ukuran target sentuh minimum (WCAG AA), memastikan kemudahan interaksi di perangkat layar sentuh.
2. **Visual Value Assistance**: Tooltip nilai yang opsional memberikan bantuan visual langsung mengenai nilai numerik saat ini ketika pengguna melakukan drag.
3. **Proximity-Based Selection**: Pada mode rentang, jika pengguna mengetuk area di dekat kedua _thumb_ yang saling berhimpit, sistem secara otomatis memilih _thumb_ yang paling dekat dengan titik sentuh untuk menghindari konflik interaksi.
