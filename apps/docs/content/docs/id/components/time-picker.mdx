# Time Picker

Komponen `JustTimePicker` menyediakan mekanisme pemilihan waktu yang presisi melalui berbagai pilihan antarmuka. Komponen ini mendukung tampilan jam bundar interaktif (dial), roda gulir vertikal tiga kolom dengan penahan magnetik (spinner), serta kolom input angka langsung, baik dalam format 12 jam (AM/PM) maupun 24 jam.

---

## Deskripsi

- **Banyak Pilihan Mode Interaksi**:
  - **Mode Dial (`.dial`)**: Jam bundar interaktif dengan jarum jam dan menit yang dapat diputar secara halus.
  - **Mode Spinner (`.spinner`)**: Tiga kolom roda penggulir vertikal dengan penguncian magnetik otomatis.
  - **Mode Input (`.input`)**: Kolom input numerik langsung dengan tombol penambah/pengurang langkah.
- **Varian Presentasi**: Tersedia sebagai widget yang disematkan langsung (inline), dropdown mengambang, maupun jendela dialog/lembar modal.
- **Fleksibilitas Format**: Beralih mudah antara format 12 jam dengan indikator AM/PM dan format militer 24 jam.
- **Batasan Waktu**: Membatasi rentang jam yang dapat dipilih melalui `firstTime`, `lastTime`, dan predikat kustom `selectableTimePredicate`.

---

## Penggunaan

### Penggunaan Dasar

Pemilih waktu dropdown dengan tampilan jarum jam 12 jam:

```dart
import 'package:flutter/widgets.dart';
import 'package:your_app/widgets/time-picker/just_time_picker.dart';

Widget buildBasicTimePicker(BuildContext context, JustTimeOfDay? selectedTime, ValueChanged<JustTimeOfDay> onTimeChanged) {
  return JustTimePicker(
    value: selectedTime,
    onChanged: onTimeChanged,
    variant: .dropdown,
    mode: .dial,
  );
}
```

### Penggunaan Lanjutan

Pemilih waktu modal dengan spinner 24 jam dan batas rentang operasional:

```dart
import 'package:flutter/widgets.dart';
import 'package:your_app/widgets/time-picker/just_time_picker.dart';

Widget buildAdvancedTimePicker(BuildContext context, JustTimeOfDay? activeTime, ValueChanged<JustTimeOfDay> onTimeChanged) {
  return JustTimePicker(
    value: activeTime,
    onChanged: onTimeChanged,
    variant: .modal,
    mode: .spinner,
    firstTime: const JustTimeOfDay(hour: 8, minute: 0),
    lastTime: const JustTimeOfDay(hour: 18, minute: 0),
  );
}
```

## Referensi API (Props)

### JustTimePicker

| Properti                  | Tipe Data                       | Nilai Default                  | Deskripsi                                                                     |
| :------------------------ | :------------------------------ | :----------------------------- | :---------------------------------------------------------------------------- |
| `value`                   | `JustTimeOfDay?`                | `null`                         | Nilai waktu yang sedang aktif.                                                |
| `onChanged`               | `ValueChanged<JustTimeOfDay>?`  | `null`                         | Callback yang dipanggil saat nilai waktu dipilih.                             |
| `variant`                 | `JustTimePickerVariant`         | `.inline`                      | Varian tampilan (`.inline`, `.modal`, `.dropdown`, `.responsive`).            |
| `mode`                    | `JustTimePickerMode`            | `.dial`                        | Paradigma interaksi (`.dial`, `.spinner`, `.input`).                          |
| `timeFormat`              | `JustTimeFormat`                | `JustTimeFormat.twelveHour`    | Format jam: `.twelveHour` (12 jam AM/PM) atau `.twentyFourHour` (24 jam).     |
| `firstTime`               | `JustTimeOfDay?`                | `null`                         | Batas awal waktu yang dapat dipilih.                                          |
| `lastTime`                | `JustTimeOfDay?`                | `null`                         | Batas akhir waktu yang dapat dipilih.                                         |
| `selectableTimePredicate` | `bool Function(JustTimeOfDay)?` | `null`                         | Predikat untuk menonaktifkan jam/menit tertentu.                              |
| `showContainer`           | `bool`                          | `true`                         | Menentukan apakah kontainer kartu luar dirender pada mode `.inline`.          |
| `locale`                  | `JustTimePickerLocale`          | `const JustTimePickerLocale()` | String lokal tanpa dependensi untuk label segmen, tombol aksi, dan tooltip.   |
| `semanticsLabel`          | `String?`                       | `null`                         | Label aksesibilitas opsional untuk kontainer pemilih waktu atau pemicu modal. |
| `style`                   | `JustTimePickerStyle?`          | `null`                         | Kustomisasi visual untuk jarum jam, angka dial, dan kolom roda putar.         |

### JustTimePickerStyle, TimePickerSpinner & JustTimePickerLocale

- **`JustTimePickerStyle.overAndUnderCenterOpacity`** (`double?`, bawaan `null`, nilai efektif `0.78`): Mengatur opasitas baris di atas dan bawah baris aktif pada roda spinner agar kontras teks di luar pusat tetap memenuhi WCAG 1.4.3.
- **`TimePickerSpinner.showContainer`** (`bool`, bawaan `true`): Mengatur apakah `TimePickerSpinner` mandiri menampilkan border dan latar kartu luar (otomatis disetel `false` saat dipakai di dalam `JustTimePicker` agar tidak ada kartu bertumpuk).
- **`JustTimePickerLocale`**: Kamu bisa menyesuaikan `hourLabel`, `minuteLabel`, `periodLabel`, `amLabel`, `pmLabel`, `cancelLabel`, `confirmLabel`, tooltip pergantian mode, serta `nextValueLabel` (bawaan `'Next value'`) dan `previousValueLabel` (bawaan `'Previous value'`) untuk deskripsi semantik naik/turun pada `TimePickerDial`.

## Aksesibilitas

- **Semantik Slider pada Roda Spinner**: Setiap kolom di `TimePickerSpinner` (jam, menit, dan periode pada format 12 jam) memakai `Semantics(container: true, slider: true)` lengkap dengan nilai aktif, nilai berikutnya/sebelumnya, serta aksi `onIncrease`/`onDecrease`, sementara item mentah di dalamnya dibungkus `ExcludeSemantics` agar tidak dibacakan ganda.
- **Kontras Luar Pusat WCAG 1.4.3**: Baris di atas dan di bawah nilai aktif pada roda spinner memakai bawaan `overAndUnderCenterOpacity: 0.78` (bisa kamu ubah lewat `JustTimePickerStyle`) supaya angka di sekitarnya tetap terbaca jelas.
- **FocusIndicator yang Jelas**: Fokus keyboard menampilkan `FocusIndicator` pada roda spinner, dial melingkar, tombol segmen/periode/mode di header, serta tombol pemicu dropdown, responsive, dan modal.
- **Navigasi Keyboard & Key-Repeat**: `TimePickerDial` maupun `TimePickerSpinner` menangani `KeyDownEvent` dan `KeyRepeatEvent` untuk tombol `ArrowUp`/`ArrowDown`/`ArrowLeft`/`ArrowRight`, `PageUp`/`PageDown`, `Home`/`End`, serta `Enter`/`Space`. Pada mode `.input`, kamu bisa mengetik angka jam dan menit secara langsung.
- **Pengumuman Pembaca Layar & Reduced Motion**: Perubahan waktu diumumkan dalam format 12 jam atau 24 jam. Saat _reduced motion_ aktif, `animations.resolve(context)` memangkas durasi animasi jarum dial, roda spinner, dan tombol periode ke `Duration.zero` (roda langsung berpindah lewat `jumpToItem`).
