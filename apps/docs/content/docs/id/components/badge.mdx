# Badge

Komponen `JustBadge` adalah lencana visual kecil yang digunakan untuk menyoroti status, memberikan tag kategori, atau menampilkan indikator pemberitahuan. Komponen ini dirancang fleksibel, mendukung berbagai variasi warna status, mode garis luar, hingga animasi denyut pendaran (_pulsing halo_).

---

## Deskripsi

- **`JustBadge`**: Lencana standar yang menampilkan label teks ringkas, ikon tambahan, dan opsional tombol tutup (_dismiss_) untuk menghapus tag.
- **`JustBadge.dot`**: Varian ringkas tanpa teks yang berfungsi sebagai indikator titik status (seperti indikator online/offline atau pemberitahuan belum dibaca).
- **`JustBadge.overlay`**: Varian pembungkus yang meletakkan lencana atau titik indikator secara menumpuk di atas widget anak (_child_), misalnya di pojok kanan atas ikon notifikasi.

---

## Usage

### Basic Usage

Contoh penggunaan dasar `JustBadge` dengan berbagai warna status dan varian gaya:

```dart
import 'package:flutter/material.dart';
import 'package:just_ui_core/just_ui_core.dart';
import 'package:just_ui_tokens/just_ui_tokens.dart';

Widget buildBasicBadges(BuildContext context) {
  return Row(
    spacing: context.justSpacing.sm,
    children: [
      // Varian Solid (Warna Penuh)
      JustBadge(
        label: 'Terbaru',
        color: JustBadgeColor.primary,
        variant: JustBadgeVariant.solid,
      ),

      // Varian Soft (Warna Transparan Lembut)
      JustBadge(
        label: 'Berhasil',
        color: JustBadgeColor.success,
        variant: JustBadgeVariant.soft,
        leading: const Icon(Icons.check, size: 12),
      ),

      // Varian Outline
      JustBadge(
        label: 'Draft',
        color: JustBadgeColor.neutral,
        variant: JustBadgeVariant.outline,
      ),
    ],
  );
}
```

### Advanced Usage

Contoh penggunaan lanjutan yang menunjukkan fitur dismissible, titik pemberitahuan berdenyut (_pulse_), dan penumpukan overlay pada ikon:

```dart
import 'package:flutter/material.dart';
import 'package:just_ui_core/just_ui_core.dart';
import 'package:just_ui_tokens/just_ui_tokens.dart';

class BadgeAdvancedDemo extends StatefulWidget {
  const BadgeAdvancedDemo({super.key});

  @override
  State<BadgeAdvancedDemo> createState() => _BadgeAdvancedDemoState();
}

class _BadgeAdvancedDemoState extends State<BadgeAdvancedDemo> {
  bool _showTag = true;

  @override
  Widget build(BuildContext context) {
    return Column(
      spacing: context.justSpacing.md,
      children: [
        // Badge dengan Tombol Hapus (Dismissible)
        if (_showTag)
          JustBadge(
            label: 'Filter Aktif',
            color: JustBadgeColor.info,
            variant: JustBadgeVariant.soft,
            onDismiss: () {
              setState(() {
                _showTag = false;
              });
            },
          ),

        // Penumpukan Indikator Pemberitahuan pada Ikon (Overlay)
        JustBadge.overlay(
          badge: const JustBadge.dot(
            color: JustBadgeColor.error,
            pulse: true, // Animasi pendaran halo aktif
          ),
          child: const Icon(Icons.notifications, size: 32),
        ),
      ],
    );
  }
}
```

## API Reference (Props)

### JustBadge

| Properti    | Tipe Data          | Nilai Bawaan (Default) | Deskripsi                                                                                                                                                                                         |
| :---------- | :----------------- | :--------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `label`     | `String?`          | `null`                 | Teks yang ditampilkan di dalam lencana. Jika diset `null`, lencana otomatis dirender sebagai titik pemberitahuan kosong (_notification dot_).                                                     |
| `color`     | `JustBadgeColor`   | `.primary`             | Pilihan skema warna status: `.primary`, `.secondary`, `.success`, `.warning`, `.error`, `.info`, `.neutral`.                                                                                      |
| `variant`   | `JustBadgeVariant` | `.solid`               | Pilihan tipe visual lencana: `.solid` (warna latar pekat), `.soft` (warna latar transparan redup), `.outline` (tanpa warna latar, dengan garis tepi), `.dot` (hanya menampilkan titik indikator). |
| `size`      | `JustBadgeSize`    | `.md`                  | Ukuran dimensi lencana: `.sm`, `.md`, `.lg`.                                                                                                                                                      |
| `leading`   | `Widget?`          | `null`                 | Widget (seperti ikon mini) yang diletakkan sebelum label teks.                                                                                                                                    |
| `onDismiss` | `VoidCallback?`    | `null`                 | Callback untuk aksi penghapusan. Jika disediakan, ikon silang kecil akan dirender di ujung kanan lencana.                                                                                         |
| `maxWidth`  | `double?`          | `null`                 | Lebar maksimum lencana. Teks yang melebihi batas ini akan otomatis terpotong dengan elipsis (`...`).                                                                                              |
| `pulse`     | `bool`             | `false`                | Hanya berlaku pada varian `.dot`. Jika `true`, mengaktifkan animasi pendaran lingkaran membesar (_pulsing halo_) di luar titik.                                                                   |

### JustBadge.overlay (Constructor)

| Properti    | Tipe Data           | Nilai Bawaan (Default) | Deskripsi                                                                 |
| :---------- | :------------------ | :--------------------- | :------------------------------------------------------------------------ |
| `child`     | `Widget`            | _Wajib (Required)_     | Widget utama yang akan ditumpuk oleh lencana (misalnya ikon atau avatar). |
| `badge`     | `Widget`            | _Wajib (Required)_     | Lencana (`JustBadge`) yang akan diletakkan di pojok atas widget utama.    |
| `alignment` | `AlignmentGeometry` | `Alignment.topRight`   | Posisi penumpukan lencana di atas widget utama.                           |

## Theming & Accessibility

### Visual Presets

Tampilan visual dari lencana menyesuaikan dengan konfigurasi preset tema:

- **Default Preset**:
  - Sudut lencana dibulatkan lembut mengikuti token `radius.sm` (atau kelengkungan penuh bulat sempurna pada varian `.dot` dan `.pill`).
  - Gradasi warna latar belakang transparan pada varian `.soft` dihitung secara dinamis dari nilai opacity warna status (sekitar 15-20%) agar terlihat menyatu secara estetis.

- **Neobrutalism Preset**:
  - Lencana dipaksa menggunakan border hitam pekat (`colors.textPrimary`) sebesar `1.5` atau `2.5` sesuai proporsi ukuran.
  - Varian `.soft` digantikan oleh warna solid yang kontras tinggi untuk memperkuat visual neobrutalis klasik.
  - Animasi denyut pendaran (`pulse`) pada varian `.dot` dioptimalkan dengan memperpendek durasi interpolasi agar selaras dengan nuansa visual yang tegas (_snappy_).

### Shimmer & Performance (Pulsing Halo)

Animasi denyut lingkaran pendaran (`pulse`) pada varian `.dot` diimplementasikan secara efisien menggunakan **`FlowDelegate`** performa tinggi:

- **Zero Layout Overhead**: Penggunaan `FlowDelegate` menggambar pendaran lingkaran langsung di atas kanvas grafik tanpa memicu kalkulasi ulang tata letak widget (_layout pass_) pada widget tree.
- Hal ini menjaga stabilitas FPS aplikasi, terutama saat banyak lencana notifikasi berdenyut sekaligus pada satu halaman daftar.

### Accessibility (WCAG AA Compliance)

1. **Rasio Kontras Minimum**:
   Warna teks label di dalam `JustBadge` dihitung menggunakan ekstensi `isAccessibleWith` untuk menjamin rasio kontras warna teks terhadap latar belakang lencana selalu memenuhi standar **WCAG AA** ($\ge$ 4.5:1 untuk teks normal).
2. **Deskripsi Semantik**:
   Bila `JustBadge` digunakan sebagai indikator status (misal: titik merah di pojok kanan ikon pesan), pengembang disarankan menyelimuti lencana tersebut dengan widget `Semantics` yang menerangkan status secara tekstual (misalnya: "3 pesan baru belum dibaca"), agar dapat dideskripsikan dengan benar oleh pembaca layar.
