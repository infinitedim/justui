# Card

Komponen `JustCard` adalah kontainer struktural yang digunakan untuk mengelompokkan informasi atau aksi terkait dalam satu blok visual. Kartu ini mendukung berbagai varian dekorasi (seperti bayangan lembut atau garis luar) dan sub-widget semantik untuk memudahkan penyusunan tata letak.

---

## Deskripsi

- **`JustCard`**: Widget kontainer utama yang menyusun area kartu. Kartu ini dapat memiliki `header` di atas, `footer` di bawah, serta otomatis mendukung efek interaksi ketuk (_onTap_) dengan umpan balik visual yang responsif.
- **Sub-Widget Semantik**: JustUI menyediakan komponen khusus seperti `JustCardHeader`, `JustCardTitle`, `JustCardDescription`, `JustCardContent`, dan `JustCardFooter` untuk memastikan konsistensi margin dan padding dalam kartu tanpa perlu mengatur jarak secara manual.

---

## Usage

### Basic Usage

Contoh penggunaan kartu sederhana dengan variant outline untuk menampilkan judul dan deskripsi singkat:

```dart
import 'package:flutter/material.dart';
import 'package:just_ui_core/just_ui_core.dart';
import 'package:just_ui_tokens/just_ui_tokens.dart';

Widget buildBasicCard(BuildContext context) {
  return JustCard(
    variant: JustCardVariant.outlined,
    child: Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      spacing: context.justSpacing.xs,
      children: [
        Text(
          'Pemberitahuan Sistem',
          style: context.justTypo.headingSm,
        ),
        Text(
          'Pembaruan perangkat lunak versi terbaru telah berhasil diunduh dan siap dipasang.',
          style: context.justTypo.bodySm,
        ),
      ],
    ),
  );
}
```

### Advanced Usage

Contoh penggunaan tingkat lanjut menggunakan sub-widget semantik, pemisahan pembatas header/footer, dan callback interaktif ketuk (_onTap_):

```dart
import 'package:flutter/material.dart';
import 'package:just_ui_core/just_ui_core.dart';
import 'package:just_ui_tokens/just_ui_tokens.dart';

Widget buildAdvancedCard(BuildContext context) {
  return JustCard(
    variant: JustCardVariant.elevated,
    onTap: () => print('Kartu diklik'),
    header: JustCardHeader(
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        spacing: context.justSpacing.xxs,
        children: [
          const JustCardTitle(child: Text('Statistik Penjualan')),
          const JustCardDescription(child: Text('Laporan bulanan kuartal kedua 2026')),
        ],
      ),
    ),
    footer: JustCardFooter(
      child: Row(
        mainAxisAlignment: MainAxisAlignment.end,
        spacing: context.justSpacing.sm,
        children: [
          JustButton(
            label: 'Unduh CSV',
            variant: .ghost,
            size: .sm,
            onPressed: () {},
          ),
          JustButton(
            label: 'Lihat Detail',
            size: .sm,
            onPressed: () {},
          ),
        ],
      ),
    ),
    child: JustCardContent(
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        spacing: context.justSpacing.sm,
        children: [
          Text(
            'Total Pendapatan: Rp 124.500.000',
            style: context.justTypo.headingLg.copyWith(
              color: context.justColors.textPrimary,
            ),
          ),
          const Text('Peningkatan sebesar 12% dibandingkan bulan lalu.'),
        ],
      ),
    ),
  );
}
```

## API Reference (Props)

### JustCard

| Properti  | Tipe Data         | Nilai Bawaan (Default) | Deskripsi                                                                                                                                                      |
| :-------- | :---------------- | :--------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `child`   | `Widget`          | _Wajib (Required)_     | Konten utama atau isi dari kartu (disarankan menggunakan `JustCardContent` untuk margin yang konsisten).                                                       |
| `variant` | `JustCardVariant` | `.elevated`            | Pilihan gaya visual kartu: `.elevated` (berbayangan lembut), `.outlined` (menggunakan border tipis), `.filled` (warna latar solid tanpa bayangan atau border). |
| `header`  | `Widget?`         | `null`                 | Widget area atas kartu (disarankan menggunakan `JustCardHeader`).                                                                                              |
| `footer`  | `Widget?`         | `null`                 | Widget area bawah kartu (disarankan menggunakan `JustCardFooter`).                                                                                             |
| `onTap`   | `VoidCallback?`   | `null`                 | Jika diisi, kartu akan mendukung aksi ketuk dengan efek penekanan transisi skala/warna.                                                                        |

### Sub-Widget Semantik Pendukung

- **`JustCardHeader`**: Mengatur padding dan pembatas bawah garis halus untuk memisahkan judul dengan konten utama.
- **`JustCardTitle`**: Menerapkan gaya teks judul bawaan (`headingMd`) secara otomatis pada anak widget.
- **`JustCardDescription`**: Menerapkan gaya teks deskripsi bawaan (`caption` dengan warna teks sekunder).
- **`JustCardContent`**: Wadah konten utama dengan padding internal standar yang seimbang.
- **`JustCardFooter`**: Mengatur padding area bawah dan pembatas atas garis halus untuk tombol-tombol aksi.

## Theming & Accessibility

### Visual Presets

Kartu beradaptasi secara otomatis mengikuti preset sistem desain yang sedang aktif:

- **Default Preset**:
  - Sudut kelengkungan kartu mengikuti `radius.lg` (12px).
  - Varian `.elevated` menerapkan bayangan bertumpuk dua lapis (_multi-layer BoxShadow_) menggunakan `JustShadows` yang berpendar halus untuk kedalaman visual yang alami.
  - Jika `onTap` aktif, kartu akan merespons gerakan kursor dengan transisi skala halus (`AnimatedScale`) dan efek hover.

- **Neobrutalism Preset**:
  - Kelengkungan sudut diubah secara tegas menggunakan token kelengkungan atau sudut siku.
  - Kartu dipaksa memiliki border hitam pekat (`colors.textPrimary`) sebesar `2.5` di seluruh varian.
  - Varian `.elevated` mengganti bayangan pendaran lembut dengan bayangan padat neobrutalis warna hitam dengan koordinat pergeseran offset tegas yang tidak pudar.
  - Saat kartu ditekan, terjadi pergeseran fisik posisi kartu (translasi X/Y) selaras dengan hilangnya bayangan padat di belakangnya (collapse shadow) secara instan.

### Accessibility (WCAG AA Compliance)

1. **Struktur Konten yang Jelas**:
   Penggunaan sub-widget semantik memastikan pembaca layar (_screen reader_) dapat memetakan hierarki elemen di dalam kartu dengan benar (membaca Header/Title terlebih dahulu, kemudian Content, lalu tindakan di Footer).
2. **Kontras Warna Teks**:
   Pewarnaan teks deskripsi sekunder di dalam `JustCardDescription` dijamin tetap memenuhi standar kontras minimum WCAG AA ($\ge$ 4.5:1 untuk teks normal) terhadap latar belakang kartu.
3. **Indikator Fokus**:
   Jika kartu memiliki parameter `onTap` dan diakses melalui keyboard, kartu akan mendapatkan ring fokus visual yang jelas ketika berada dalam fokus navigasi untuk memudahkan aksesibilitas disabilitas motorik.
