# Scroll Area

`JustScrollArea` adalah kontainer gulir berkinerja tinggi yang menggantikan scrollbar bawaan sistem operasi dengan bilah geser kustom yang mematuhi estetika sistem desain. Komponen ini mendukung efek tepi memudar transparan (_fade edges_) di batas atas dan bawah gulungan, tombol kembali ke atas otomatis, dan pemicu pemuatan data tanpa batas (_infinite scroll_).

## Usage

### Basic

Berikut adalah contoh penggunaan dasar `JustScrollArea` untuk membungkus daftar konten gulir sederhana.

```dart
import 'package:flutter/material.dart';
import 'package:your_app/core/just_ui_core.dart';

class BasicScrollAreaExample extends StatelessWidget {
  const BasicScrollAreaExample({super.key});

  @override
  Widget build(BuildContext context) {
    return Container(
      height: 300,
      decoration: BoxDecoration(
        border: Border.all(color: context.justColors.border),
        borderRadius: .all(context.justRadius.md),
      ),
      child: JustScrollArea(
        child: Column(
          children: List.generate(
            50,
            (index) => ListTile(
              title: Text('Item Ke-$index'),
            ),
          ),
        ),
      ),
    );
  }
}
```

### Advanced

Contoh penggunaan lanjutan dengan pemudaran tepi menggunakan `ShaderMask`, tombol kembali ke atas otomatis, pemutaran keyboard, dan pagination tak terbatas (_infinite scroll_).

```dart
import 'package:flutter/material.dart';
import 'package:your_app/core/just_ui_core.dart';

class AdvancedScrollAreaExample extends StatefulWidget {
  const AdvancedScrollAreaExample({super.key});

  @override
  State<AdvancedScrollAreaExample> createState() => _AdvancedScrollAreaExampleState();
}

class _AdvancedScrollAreaExampleState extends State<AdvancedScrollAreaExample> {
  final List<String> _items = List.generate(20, (index) => 'Item Awal Ke-$index');
  bool _isLoadingMore = false;

  void _loadMoreData() async {
    if (_isLoadingMore) return;
    setState(() => _isLoadingMore = true);

    // Simulasi delay jaringan
    await Future.delayed(const Duration(seconds: 2));

    setState(() {
      _items.addAll(List.generate(10, (index) => 'Item Tambahan Ke-${_items.length + index}'));
      _isLoadingMore = false;
    });
  }

  @override
  Widget build(BuildContext context) {
    return Container(
      height: 400,
      decoration: BoxDecoration(
        border: Border.all(color: context.justColors.border),
        borderRadius: .all(context.justRadius.lg),
      ),
      child: JustScrollArea(
        direction: Axis.vertical,
        showScrollbar: true,
        fadeEdges: true,
        fadeMode: JustScrollFadeMode.mask,
        scrollToTopButton: true,
        scrollToTopThreshold: 300.0,
        keyboardScrollStep: 60.0,
        onReachBottom: _loadMoreData, // Memicu muat data saat mendekati batas bawah
        child: ListView.builder(
          shrinkWrap: true,
          physics: const NeverScrollableScrollPhysics(), // Scroll dikontrol penuh oleh JustScrollArea
          itemCount: _items.length + (_isLoadingMore ? 1 : 0),
          itemBuilder: (context, index) {
            if (index == _items.length) {
              return const Padding(
                padding: EdgeInsets.all(16.0),
                child: Center(child: CircularProgressIndicator()),
              );
            }
            return ListTile(title: Text(_items[index]));
          },
        ),
      ),
    );
  }
}
```

## API Reference (Props)

### JustScrollArea

| Properti               | Tipe Data              | Nilai Bawaan                 | Deskripsi                                                                                                                                      |
| ---------------------- | ---------------------- | ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `child`                | `Widget`               | _Wajib_                      | Widget anak berisi daftar konten yang dapat digulir.                                                                                           |
| `direction`            | `Axis`                 | `Axis.vertical`              | Arah gulir utama kontainer (vertikal atau horizontal).                                                                                         |
| `showScrollbar`        | `bool`                 | `true`                       | Menentukan apakah bilah geser kustom JustUI ditampilkan secara visual.                                                                         |
| `fadeEdges`            | `bool`                 | `false`                      | Jika true, menerapkan efek gradasi transparan di batas tepi gulungan (menandakan adanya konten lanjutan).                                      |
| `fadeMode`             | `JustScrollFadeMode`   | `JustScrollFadeMode.overlay` | Teknik pemudaran tepi: `.overlay` (container gradasi di atas viewport) atau `.mask` (masking piksel alpha asli anak menggunakan `ShaderMask`). |
| `scrollToTopButton`    | `bool`                 | `false`                      | Menampilkan tombol kembali ke posisi awal secara otomatis saat digulir jauh.                                                                   |
| `scrollToTopThreshold` | `double`               | `400.0`                      | Jarak batas minimal gulir (dalam piksel) untuk memunculkan tombol kembali ke atas.                                                             |
| `onReachBottom`        | `VoidCallback?`        | `null`                       | Callback yang dipicu ketika guliran mendekati batas bawah kontainer (berguna untuk _infinite scroll_).                                         |
| `keyboardScrollStep`   | `double`               | `50.0`                       | Jarak lompatan gulir (dalam piksel) per satu ketukan tombol panah pada keyboard.                                                               |
| `semanticsLabel`       | `String?`              | `null`                       | Label aksesibilitas opsional yang dibacakan untuk area kontainer gulir.                                                                        |
| `thumbVisibility`      | `bool?`                | `null`                       | Menentukan apakah thumb scrollbar selalu terlihat (bawaannya `false`).                                                                         |
| `trackVisibility`      | `bool?`                | `null`                       | Menentukan apakah track scrollbar selalu terlihat (berlaku ketika `thumbVisibility` bernilai `true`).                                          |
| `style`                | `JustScrollAreaStyle?` | `null`                       | Kustomisasi visual per instance untuk tepi memudar, tampilan scrollbar, radius fokus, dan smooth scroll.                                       |

### JustScrollAreaStyle

Kamu bisa mengatur tepi memudar, geometri scrollbar, visibilitas, radius indikator fokus, dan smooth scroll per instance lewat `JustScrollAreaStyle`, termasuk properti berikut:

| Properti                   | Tipe Data       | Nilai Bawaan | Deskripsi                                                                                                   |
| -------------------------- | --------------- | ------------ | ----------------------------------------------------------------------------------------------------------- |
| `thumbVisibility`          | `bool?`         | `null`       | Menjaga thumb scrollbar tetap terlihat saat bernilai `true`.                                                |
| `trackVisibility`          | `bool?`         | `null`       | Menjaga track scrollbar tetap terlihat saat bernilai `true` (aktif bila `thumbVisibility` bernilai `true`). |
| `scrollbarTrackRadius`     | `Radius?`       | `null`       | Radius sudut track scrollbar (dipaksa `Radius.zero` pada Neobrutalism).                                     |
| `scrollbarCrossAxisMargin` | `double?`       | `null`       | Margin sumbu silang (_cross-axis_) untuk track scrollbar (bawaannya `0.0`).                                 |
| `focusBorderRadius`        | `BorderRadius?` | `null`       | Radius sudut untuk `FocusIndicator` keyboard di sekeliling area gulir.                                      |

## Theming & Accessibility

### Penjelasan Kustomisasi Preset & Style

- **Default Style**: Bilah geser kustom memakai sudut membulat (`Radius.circular(3.0)` secara bawaan) dan warna thumb lembut berbasis `colors.textSecondary`, dengan opsi visibilitas thumb/track permanen lewat `thumbVisibility`, `trackVisibility`, dan `JustScrollAreaStyle`.
- **Neobrutalism Style**: Memaksa sudut tajam `Radius.zero` pada thumb maupun track scrollbar (`scrollbarTrackRadius`), selaras dengan token preset yang tegas.

### Integrasi Keyboard & ShaderMask

- **Navigasi Keyboard Desktop**: Mengikat kontainer dengan `FocusNode` internal yang menangani `KeyDownEvent` dan `KeyRepeatEvent` (menahan tombol akan menggulir terus-menerus). Tombol `Home` dan `End` melompat ke awal (`0.0`) atau akhir (`maxScrollExtent`), `PageUp` dan `PageDown` menggulir sejauh satu viewport, dan tombol panah (`ArrowUp`/`ArrowDown` untuk vertikal, `ArrowLeft`/`ArrowRight` untuk horizontal) melangkah sebesar `keyboardScrollStep`.
- **ShaderMasking Tepi**: Saat `fadeMode` disetel ke `JustScrollFadeMode.mask`, gradien alpha multi-stop `ShaderMask` mencegah teks atau gambar terpotong kasar di ujung batas viewport.

### Pemenuhan Standar WCAG AA

- **FocusIndicator & Label Kontainer Semantik**: Menampilkan `FocusIndicator` di sekeliling area gulir saat fokus lewat keyboard (radius bisa diatur lewat `JustScrollAreaStyle.focusBorderRadius`), serta membungkus kontainer dengan `Semantics(container: true, label: semanticsLabel)`.
- **Target Sentuh Scroll-to-Top & Reduced Motion**: Tombol mengambang scroll-to-top memiliki area sentuh minimal `48x48`, `FocusIndicator` sendiri, dan label semantik `'Scroll to top'`. Saat _reduced motion_ aktif (`animations.resolve(context)` menyelesaikan `fast` ke `Duration.zero`), gulir keyboard dan tombol scroll-to-top melewati animasi/smooth scroll dan langsung melompat dengan `jumpTo`.
