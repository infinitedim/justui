# Sidebar

`JustSidebar` adalah komponen navigasi samping yang kokoh dan responsif untuk antarmuka desktop, tablet, maupun dashboard administratif. Komponen ini mendukung perutean bertingkat rekursif, status ciut (_collapsed_), dan otomatis menyesuaikan lebar tata letaknya secara mandiri saat mendeteksi layar ukuran kecil.

## Usage

### Basic

Berikut adalah contoh penggunaan dasar `JustSidebar` untuk menu navigasi satu tingkat.

```dart
import 'package:flutter/material.dart';
import 'package:just_ui_core/just_ui_core.dart';
import 'package:just_ui_tokens/just_ui_tokens.dart';

class BasicSidebarExample extends StatefulWidget {
  const BasicSidebarExample({super.key});

  @override
  State<BasicSidebarExample> createState() => _BasicSidebarExampleState();
}

class _BasicSidebarExampleState extends State<BasicSidebarExample> {
  int _selectedIdx = 0;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Row(
        children: [
          JustSidebar(
            selectedIndex: _selectedIdx,
            onItemSelected: (index) {
              setState(() {
                _selectedIdx = index;
              });
            },
            items: const [
              JustSidebarItem(
                label: 'Dashboard',
                icon: Icon(Icons.dashboard_outlined),
              ),
              JustSidebarItem(
                label: 'Transaksi',
                icon: Icon(Icons.receipt_long),
              ),
              JustSidebarItem(
                label: 'Pengaturan',
                icon: Icon(Icons.settings),
              ),
            ],
          ),
          const VerticalDivider(width: 1),
          Expanded(
            child: Center(
              child: Text('Konten Halaman Ke-$_selectedIdx'),
            ),
          ),
        ],
      ),
    );
  }
}
```

### Advanced

Contoh penggunaan lanjutan dengan menu bersarang (rekursif), header profil pengguna, footer keluar akun, dan opsi status ciut (_collapsed_).

```dart
import 'package:flutter/material.dart';
import 'package:just_ui_core/just_ui_core.dart';
import 'package:just_ui_tokens/just_ui_tokens.dart';

class AdvancedSidebarExample extends StatefulWidget {
  const AdvancedSidebarExample({super.key});

  @override
  State<AdvancedSidebarExample> createState() => _AdvancedSidebarExampleState();
}

class _AdvancedSidebarExampleState extends State<AdvancedSidebarExample> {
  int _selectedIdx = 0;
  bool _isSidebarCollapsed = false;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Row(
        children: [
          JustSidebar(
            isCollapsed: _isSidebarCollapsed,
            variant: JustSidebarVariant.inset,
            header: Padding(
              padding: const EdgeInsets.all(16.0),
              child: Row(
                children: [
                  const JustAvatar(name: 'Admin JustUI', size: JustAvatarSize.md),
                  if (!_isSidebarCollapsed) ...[
                    const SizedBox(width: 12),
                    const Expanded(
                      child: Text(
                        'Administrator',
                        style: TextStyle(fontWeight: FontWeight.bold),
                        overflow: TextOverflow.ellipsis,
                      ),
                    ),
                  ],
                ],
              ),
            ),
            footer: JustIconButton(
              icon: Icon(_isSidebarCollapsed ? Icons.chevron_right : Icons.chevron_left),
              tooltip: _isSidebarCollapsed ? 'Buka Sidebar' : 'Tutup Sidebar',
              onPressed: () {
                setState(() {
                  _isSidebarCollapsed = !_isSidebarCollapsed;
                });
              },
            ),
            selectedIndex: _selectedIdx,
            onItemSelected: (index) {
              setState(() {
                _selectedIdx = index;
              });
            },
            items: [
              const JustSidebarItem(
                label: 'Dashboard',
                icon: Icon(Icons.home),
              ),
              JustSidebarItem(
                label: 'Manajemen Data',
                icon: const Icon(Icons.folder_open),
                children: [
                  JustSidebarItem(
                    label: 'Daftar Klien',
                    icon: const Icon(Icons.people_outline),
                    onTap: () => _navigateTo('/clients'),
                  ),
                  JustSidebarItem(
                    label: 'Hak Akses',
                    icon: const Icon(Icons.lock_outline),
                    onTap: () => _navigateTo('/permissions'),
                  ),
                ],
              ),
              const JustSidebarItem(
                label: 'Laporan Analisis',
                icon: Icon(Icons.analytics),
              ),
            ],
          ),
          const VerticalDivider(width: 1),
          Expanded(
            child: Center(
              child: Text('Halaman aktif ke-$_selectedIdx'),
            ),
          ),
        ],
      ),
    );
  }

  void _navigateTo(String route) {
    print('Navigasi ke: $route');
  }
}
```

## API Reference (Props)

### JustSidebar

| Properti         | Tipe Data               | Nilai Bawaan                  | Deskripsi                                                                                                                                                              |
| ---------------- | ----------------------- | ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `items`          | `List<JustSidebarItem>` | _Wajib_                       | Rangkaian menu item navigasi samping yang dapat bercabang secara bertingkat (rekursif).                                                                                |
| `selectedIndex`  | `int`                   | `0`                           | Indeks item sidebar yang aktif saat ini.                                                                                                                               |
| `onItemSelected` | `ValueChanged<int>?`    | `null`                        | Callback yang dipicu ketika suatu item navigasi utama diketuk.                                                                                                         |
| `header`         | `Widget?`               | `null`                        | Widget area atas sidebar (misal: logo perusahaan atau profil ringkas pengguna).                                                                                        |
| `footer`         | `Widget?`               | `null`                        | Widget area bawah sidebar (misal: tombol keluar akun atau tombol ciut).                                                                                                |
| `width`          | `double`                | `260.0`                       | Lebar panel sidebar saat dalam kondisi terbuka penuh.                                                                                                                  |
| `collapsedWidth` | `double`                | `68.0`                        | Lebar minimal panel sidebar saat dalam kondisi menciut (_collapsed_).                                                                                                  |
| `isCollapsed`    | `bool`                  | `false`                       | Status penciutan aktif panel sidebar.                                                                                                                                  |
| `variant`        | `JustSidebarVariant`    | `JustSidebarVariant.default_` | Gaya tata letak sidebar: `.default_` (menempel tepi layar), `.floating` (mengambang bebas berbayangan), atau `.inset` (terisolasi di dalam bingkai kontainer halaman). |

### JustSidebarItem

| Properti   | Tipe Data                | Nilai Bawaan | Deskripsi                                                                                  |
| ---------- | ------------------------ | ------------ | ------------------------------------------------------------------------------------------ |
| `label`    | `String`                 | _Wajib_      | Label teks menu navigasi samping.                                                          |
| `icon`     | `Widget?`                | `null`       | Ikon visual pendamping teks menu.                                                          |
| `onTap`    | `VoidCallback?`          | `null`       | Callback aksi opsional saat item diketuk (jika tidak menggunakan `onItemSelected` global). |
| `children` | `List<JustSidebarItem>?` | `null`       | Daftar submenu anak untuk menu bertingkat yang dapat ditutup-buka secara rekursif.         |

## Theming & Accessibility

### Penjelasan Kustomisasi Preset & Style

- **Default Style**: Animasi perubahan lebar menggunakan `AnimatedContainer` berdurasi `JustDuration.normal` (250ms) dengan kurva `JustCurves.default_`. Sudut lengkung mengikuti `radius.lg` pada varian `.inset`.
- **Neobrutalism Style**: Border vertikal dipaksa berwarna hitam pekat (`colors.textPrimary`) dengan ketebalan border `2.5`. Bayangan kontainer bertipe bayangan solid dinamis tanpa blur, dan sudut kelengkungan disetel kaku (`radius.none` atau `radius.xs`).

### Auto-Collapse Responsif & Animasi Folder

- **Auto-Collapse**: Jika lebar layar perangkat terdeteksi $\le$ `JustBreakpoints.md` (768px), sidebar secara otomatis menciutkan diri menjadi lebar minimal `68.0` px tanpa memedulikan nilai parameter `isCollapsed` yang disuplai oleh pengembang. Hal ini memastikan ruang baca di layar tablet/mobile tetap lapang.
- **Folder Rekursif**: Folder anak bercabang ditata secara rekursif dengan penambahan margin spasi `depth * 16.0` px di setiap tingkatan folder dengan animasi pelipatan vertikal menggunakan `SizeTransition`.
- **Balon Petunjuk (Tooltip)**: Jika laci navigasi ciut (`isCollapsed` bernilai true), teks nama item yang tersembunyi secara visual akan dimunculkan kembali sebagai balon petunjuk layang (`JustTooltipOverlay`) saat kursor mouse menyentuh ikon (hover) untuk menjaga kejelasan makna navigasi.

### Pemenuhan Standar WCAG AA

- **Aksesibilitas Kontras & Semantik**: Status pelipatan sidebar (`isCollapsed`) diumumkan secara jelas oleh pembaca layar. Fokus keyboard didukung menggunakan `FocusNode` internal untuk mempermudah navigasi beruntun ke setiap item menu menggunakan tombol panah atas/bawah dan tombol spasi/enter. Warna teks dan latar belakang diatur memenuhi rasio kontras $\ge$ 4.5:1 untuk menjamin keterbacaan yang tinggi.
