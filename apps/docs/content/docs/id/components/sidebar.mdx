# Sidebar

`JustSidebar` adalah komponen navigasi samping yang kokoh dan responsif untuk antarmuka desktop, tablet, maupun dashboard administratif. Komponen ini mendukung perutean bertingkat rekursif, status ciut (_collapsed_), dan otomatis menyesuaikan lebar tata letaknya secara mandiri saat mendeteksi layar ukuran kecil.

## Usage

### Basic

Berikut adalah contoh penggunaan dasar `JustSidebar` untuk menu navigasi satu tingkat.

```dart
import 'package:material_ui/material_ui.dart';
import 'package:your_app/core/just_ui_core.dart';

class BasicSidebarExample extends StatefulWidget {
  const BasicSidebarExample({super.key});

  @override
  State<BasicSidebarExample> createState() => _BasicSidebarExampleState();
}

class _BasicSidebarExampleState extends State<BasicSidebarExample> {
  int _selectedIdx = 0;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Row(
        children: [
          JustSidebar(
            selectedIndex: _selectedIdx,
            onItemSelected: (index) {
              setState(() {
                _selectedIdx = index;
              });
            },
            items: const [
              JustSidebarItem(
                label: 'Dashboard',
                icon: Icon(Icons.dashboard_outlined),
              ),
              JustSidebarItem(
                label: 'Transaksi',
                icon: Icon(Icons.receipt_long),
              ),
              JustSidebarItem(
                label: 'Pengaturan',
                icon: Icon(Icons.settings),
              ),
            ],
          ),
          const VerticalDivider(width: 1.0),
          Expanded(
            child: Center(
              child: Text('Konten Halaman Ke-$_selectedIdx'),
            ),
          ),
        ],
      ),
    );
  }
}
```

### Advanced

Contoh penggunaan lanjutan dengan menu bersarang (rekursif), header profil pengguna, footer keluar akun, dan opsi status ciut (_collapsed_).

```dart
import 'package:material_ui/material_ui.dart';
import 'package:your_app/core/just_ui_core.dart';

class AdvancedSidebarExample extends StatefulWidget {
  const AdvancedSidebarExample({super.key});

  @override
  State<AdvancedSidebarExample> createState() => _AdvancedSidebarExampleState();
}

class _AdvancedSidebarExampleState extends State<AdvancedSidebarExample> {
  int _selectedIdx = 0;
  bool _isSidebarCollapsed = false;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Row(
        children: [
          JustSidebar(
            isCollapsed: _isSidebarCollapsed,
            variant: .inset,
            header: Padding(
              padding: const .all(16.0),
              child: Row(
                children: [
                  const JustAvatar(name: 'Admin JustUI', size: .md),
                  if (!_isSidebarCollapsed) ...[
                    const SizedBox(width: 12.0),
                    const Expanded(
                      child: Text(
                        'Administrator',
                        style: TextStyle(fontWeight: .bold),
                        overflow: .ellipsis,
                      ),
                    ),
                  ],
                ],
              ),
            ),
            footer: JustIconButton(
              icon: Icon(_isSidebarCollapsed ? Icons.chevron_right : Icons.chevron_left),
              tooltip: _isSidebarCollapsed ? 'Buka Sidebar' : 'Tutup Sidebar',
              onPressed: () {
                setState(() {
                  _isSidebarCollapsed = !_isSidebarCollapsed;
                });
              },
            ),
            selectedIndex: _selectedIdx,
            onItemSelected: (index) {
              setState(() {
                _selectedIdx = index;
              });
            },
            items: [
              const JustSidebarItem(
                label: 'Dashboard',
                icon: Icon(Icons.home),
              ),
              JustSidebarItem(
                label: 'Manajemen Data',
                icon: const Icon(Icons.folder_open),
                children: [
                  JustSidebarItem(
                    label: 'Daftar Klien',
                    icon: const Icon(Icons.people_outline),
                    onTap: () => _navigateTo('/clients'),
                  ),
                  JustSidebarItem(
                    label: 'Hak Akses',
                    icon: const Icon(Icons.lock_outline),
                    onTap: () => _navigateTo('/permissions'),
                  ),
                ],
              ),
              const JustSidebarItem(
                label: 'Laporan Analisis',
                icon: Icon(Icons.analytics),
              ),
            ],
          ),
          const VerticalDivider(width: 1.0),
          Expanded(
            child: Center(
              child: Text('Halaman aktif ke-$_selectedIdx'),
            ),
          ),
        ],
      ),
    );
  }

  void _navigateTo(String route) {
    print('Navigasi ke: $route');
  }
}
```

## API Reference (Props)

### JustSidebar

| Properti         | Tipe Data               | Nilai Bawaan                  | Deskripsi                                                                                                                                                                         |
| ---------------- | ----------------------- | ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `items`          | `List<JustSidebarItem>` | _Wajib_                       | Rangkaian menu item navigasi samping yang dapat bercabang secara bertingkat (rekursif).                                                                                           |
| `selectedIndex`  | `int`                   | `0`                           | Indeks item sidebar yang aktif saat ini.                                                                                                                                          |
| `onItemSelected` | `ValueChanged<int>?`    | `null`                        | Callback yang dipicu ketika suatu item navigasi utama diketuk.                                                                                                                    |
| `header`         | `Widget?`               | `null`                        | Widget area atas sidebar (misal: logo perusahaan atau profil ringkas pengguna).                                                                                                   |
| `footer`         | `Widget?`               | `null`                        | Widget area bawah sidebar (misal: tombol keluar akun atau tombol ciut).                                                                                                           |
| `width`          | `double`                | `260.0`                       | Lebar panel sidebar saat dalam kondisi terbuka penuh.                                                                                                                             |
| `collapsedWidth` | `double`                | `68.0`                        | Lebar minimal panel sidebar saat dalam kondisi menciut (_collapsed_).                                                                                                             |
| `isCollapsed`    | `bool`                  | `false`                       | Status penciutan aktif panel sidebar.                                                                                                                                             |
| `autoCollapse`   | `bool`                  | `true`                        | Menentukan apakah sidebar menciut otomatis pada viewport yang lebarnya sama dengan atau di bawah `JustBreakpoints.md`. Set ke `false` untuk panel tertanam atau kontainer sempit. |
| `variant`        | `JustSidebarVariant`    | `JustSidebarVariant.default_` | Gaya tata letak sidebar: `.default_` (menempel tepi layar), `.floating` (mengambang bebas berbayangan), atau `.inset` (terisolasi di dalam bingkai kontainer halaman).            |
| `style`          | `JustSidebarStyle?`     | `null`                        | Kustomisasi visual per instance untuk border panel, radius, warna item terpilih, jarak antar item, padding, dan tipografi.                                                        |
| `semanticsLabel` | `String?`               | `null`                        | Label aksesibilitas opsional yang dibacakan untuk kontainer navigasi sidebar.                                                                                                     |

### JustSidebarItem

| Properti   | Tipe Data                | Nilai Bawaan | Deskripsi                                                                                  |
| ---------- | ------------------------ | ------------ | ------------------------------------------------------------------------------------------ |
| `label`    | `String`                 | _Wajib_      | Label teks menu navigasi samping.                                                          |
| `icon`     | `Widget`                 | _Wajib_      | Ikon visual pendamping teks menu.                                                          |
| `onTap`    | `VoidCallback?`          | `null`       | Callback aksi opsional saat item diketuk (jika tidak menggunakan `onItemSelected` global). |
| `children` | `List<JustSidebarItem>?` | `null`       | Daftar submenu anak untuk menu bertingkat yang dapat ditutup-buka secara rekursif.         |

### JustSidebarStyle

Kamu bisa mengatur tampilan panel dan item sidebar per instance lewat `JustSidebarStyle`, termasuk properti berikut:

| Properti                  | Tipe Data       | Nilai Bawaan | Deskripsi                                                                                                                      |
| ------------------------- | --------------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| `borderColor`             | `Color?`        | `null`       | Warna border kustom panel sidebar (bawaannya `colors.textPrimary` pada Neobrutalism atau `colors.borderDefault` pada Default). |
| `borderRadius`            | `BorderRadius?` | `null`       | Radius sudut kustom untuk panel sidebar.                                                                                       |
| `selectedBackgroundColor` | `Color?`        | `null`       | Warna latar belakang kustom untuk item sidebar yang sedang aktif terpilih.                                                     |
| `selectedForegroundColor` | `Color?`        | `null`       | Warna teks dan ikon kustom untuk item sidebar yang sedang aktif terpilih.                                                      |
| `itemSpacing`             | `double?`       | `null`       | Jarak vertikal kustom antar item sidebar (bawaannya `0.0`).                                                                    |

## Theming & Accessibility

### Penjelasan Kustomisasi Preset & Style

- **Default Style**: Transisi lebar panel menggunakan `AnimationController` yang mengikuti `animations.normal` (`animations.resolve(context)`). Sudut lengkung mengikuti `radius.xl` pada varian `.floating` dan `radius.lg` pada `.inset`. Kamu bisa menyesuaikan border panel, radius, warna latar/teks item terpilih, dan jarak antar item lewat `JustSidebarStyle`.
- **Neobrutalism Style**: Menggunakan border tegas `colors.textPrimary` (`presetTokens.borderWidth`), sudut tajam `BorderRadius.zero` pada panel, serta bayangan offset solid pada varian `.floating` dan `.inset`.

### Auto-Collapse Responsif, Keamanan Tinggi Tak Terbatas & Animasi Folder

- **Auto-Collapse**: Secara bawaan (`autoCollapse: true`), saat lebar viewport sama dengan atau di bawah `JustBreakpoints.md` (768px), sidebar menciut otomatis ke `collapsedWidth` (`68.0` px) agar ruang konten tetap lega di layar sempit. Kamu bisa mengatur `autoCollapse: false` saat menanamkan `JustSidebar` di panel tertanam, pratinjau ringkas, atau kontainer sempit yang harus tetap terbuka.
- **Aman untuk Tinggi Tak Terbatas (Unbounded Height)**: `JustSidebar` memeriksa `constraints.hasBoundedHeight` lewat `LayoutBuilder`. Di dalam kontainer bertinggi terbatas, item akan memenuhi ruang dan menggulir melalui `Expanded(child: SingleChildScrollView(...))`; sedangkan di tata letak tanpa batas tinggi, ukurannya menyesuaikan isi (`MainAxisSize.min`) tanpa memicu error layout.
- **Folder Rekursif**: Submenu anak ditata secara rekursif dengan indentasi `depth * 16.0` px di tiap tingkatan dan animasi lipat vertikal menggunakan `SizeTransition`.
- **Balon Petunjuk (Tooltip)**: Saat sidebar menciut, mengarahkan kursor ke item menampilkan labelnya pada `JustTooltipOverlay` agar navigasi berbasis ikon tetap jelas.

### Pemenuhan Standar WCAG AA

- **FocusIndicator & Semantik Tanpa Duplikasi**: Baik item daun maupun header folder menampilkan `FocusIndicator` saat menerima fokus keyboard dan membungkus kontennya dalam `Semantics(..., excludeSemantics: true)` (dengan `button: true`, status `selected` atau `expanded`, `enabled`, dan `label`) agar pembaca layar tidak membacakan teks anak dua kali. Panel luar membungkus kontainer dengan `Semantics(container: true, explicitChildNodes: true, label: semanticsLabel)`.
- **Pengecualian Fokus & Semantik Folder Tertutup**: Item anak di dalam folder yang tertutup dibungkus dengan `ExcludeFocus` dan `ExcludeSemantics` (`excluding: !_isExpanded`), sehingga item tersembunyi dilewati oleh navigasi fokus keyboard maupun pembaca layar sampai folder dibuka.
- **Reduced Motion & Kontras**: Controller penciutan sidebar dan buka-tutup folder menghormati `animations.resolve(context)` dan langsung berpindah ke kondisi target ketika durasi bernilai `Duration.zero`. Kontras warna teks dan latar belakang memenuhi >= 4.5:1.
