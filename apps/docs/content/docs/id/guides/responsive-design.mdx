Membangun antarmuka yang tampil sempurna di berbagai ukuran layar—mulai dari ponsel cerdas berlayar kecil, tablet, hingga monitor desktop ultra-lebar—adalah kebutuhan wajib aplikasi modern. JustUI menyediakan alat bantu tata letak responsif yang tangguh di dalam package `just_ui_tokens`, didukung oleh optimalisasi responsivitas tingkat komponen.

---

## Batas Ukuran Layar (JustBreakpoints)

JustUI menyediakan konstanta batas ukuran lebar layar (`JustBreakpoints` pada berkas `breakpoints.dart`) yang digunakan untuk mendeteksi tipe perangkat secara instan dan mengubah tata letak aplikasi secara dinamis:

| Token Breakpoint      | Nilai Lebar | Kategori Perangkat                                                        |
| :-------------------- | :---------- | :------------------------------------------------------------------------ |
| `JustBreakpoints.sm`  | `640.0` px  | Perangkat mobile dalam orientasi lanskap atau tablet berukuran kecil.     |
| `JustBreakpoints.md`  | `768.0` px  | Perangkat tablet dalam orientasi potret (contoh: iPad Mini/iPad standar). |
| `JustBreakpoints.lg`  | `1024.0` px | Tablet dalam orientasi lanskap atau monitor desktop standar.              |
| `JustBreakpoints.xl`  | `1280.0` px | Monitor desktop berukuran lebar.                                          |
| `JustBreakpoints.xxl` | `1536.0` px | Monitor desktop dengan resolusi tinggi atau layar ultra-lebar.            |

### Cara Penggunaan di Flutter

Anda dapat menggunakan breakpoints ini di dalam metode `build` widget Anda bersama dengan lebar layar saat ini (`MediaQuery.of(context).size.width` atau melalui ekstensi core):

```dart
Widget build(BuildContext context) {
  final double screenWidth = MediaQuery.of(context).size.width;

  if (screenWidth >= JustBreakpoints.lg) {
    return const DesktopLayout();
  } else if (screenWidth >= JustBreakpoints.md) {
    return const TabletLayout();
  } else {
    return const MobileLayout();
  }
}
```

## Sistem Spacing & Celah Grid (JustSpacing)

Konsistensi jarak sangat memengaruhi kerapian antarmuka. JustUI menggunakan **sistem kisi 4px** untuk mendefinisikan margin, padding, dan celah antar elemen. Konstanta ini disediakan dalam kelas `JustSpacing` dan kelas pembantu `JustGap` (yang langsung mengembalikan widget `SizedBox` instan):

- **`xxs` / `JustGap.xxs`** (`2.0` px): Jarak mikro untuk ikon segaris atau teks pembantu yang sangat rapat.
- **`xs` / `JustGap.xs`** (`4.0` px): Jarak ketat untuk elemen pembantu atau lencana.
- **`sm` / `JustGap.sm`** (`8.0` px): Jarak dasar standar antar blok konten kecil.
- **`md` / `JustGap.md`** (`12.0` px): Jarak sedang (padding bawaan untuk lencana, kartu kecil, atau tombol).
- **`lg` / `JustGap.lg`** (`16.0` px): Jarak besar (padding bawaan untuk kartu utama, kontainer, atau margin tepi halaman).
- **`xl` / `JustGap.xl`** (`24.0` px): Jarak ekstra besar (padding kartu lebar, judul besar, atau jarak antar komponen besar).
- **`xxl` / `JustGap.xxl`** (`32.0` px): Jarak pemisah antar seksi konten halaman.
- **`xxxl` / `JustGap.xxxl`** (`48.0` px): Batas terluar tata letak halaman aplikasi.
- **`huge` / `JustGap.huge`** (`64.0` px): Jarak vertikal masif (biasanya untuk halaman hero atau welcome screen).

### Membuat Insets Berbasis Token

Hindari menulis angka padding manual secara acak. Gunakan fungsi utilitas insets JustUI:

```dart
padding: JustSpacing.insets(horizontal: JustSpacing.lg, vertical: JustSpacing.md)
// Menghasilkan EdgeInsets.symmetric(horizontal: 16.0, vertical: 12.0)
```

## Fluid Typography (Tipografi Cair)

Ukuran teks yang terlalu besar pada layar monitor desktop dapat terlihat sangat merusak tata letak jika ditampilkan pada layar ponsel. JustUI memecahkan masalah ini dengan konsep **Fluid Typography** melalui kelas `JustFluidTypography`.

### 1. Interpolasi Ukuran Linier (`fluid`)

Metode `.fluid()` menghitung ukuran font secara dinamis berdasarkan lebar layar saat ini. Ukuran teks akan bergeser secara halus (_interpolasi linier_) antara batas ukuran minimum (`minSize`) dan batas ukuran maksimum (`maxSize`) saat lebar layar bergerak dari batas bawah (`minWidth`: 640px) ke batas atas (`maxWidth`: 1024px).

### 2. Penyesuaian Tinggi Baris Adaptif (`withAdaptiveHeight`)

Ukuran font yang dinamis memerlukan tinggi baris (_line height_) yang fleksibel agar tidak terjadi tumpang tindih teks atau jarak antar baris yang terlalu renggang:

- **Teks Kecil ($\le$ 12px)** mendapatkan tinggi baris longgar (`1.6`) agar huruf-huruf kecil tetap mudah dibaca.
- **Teks Besar ($\ge$ 36px)** mendapatkan tinggi baris rapat (`1.15`) untuk menghindari jarak kosong berlebih di antara baris teks judul yang besar.

## Responsivitas Bawaan Tingkat Komponen

Beberapa komponen JustUI dirancang dengan kecerdasan responsif internal sehingga Anda tidak perlu menulis kode deteksi layar tambahan secara manual.

### 1. Auto-Collapse pada `JustSidebar`

Komponen laci navigasi samping (`JustSidebar`) secara otomatis menyesuaikan dirinya terhadap ukuran layar perangkat pengguna:

- Jika lebar layar terpantau **lebih kecil atau sama dengan `JustBreakpoints.md` (768px)**, sidebar akan menciut secara otomatis menjadi ukuran ciut bawaan (`collapsedWidth` sebesar 68px) tanpa memedulikan status `isCollapsed` yang didefinisikan oleh pengembang.
- Ketika sidebar menciut, label menu teks yang disembunyikan akan secara otomatis dialihkan dan ditampilkan kembali sebagai balon petunjuk layang (`JustTooltipOverlay`) saat kursor menyentuh ikon menu tersebut, menjaga kemudahan navigasi pengguna tablet atau mobile.

### 2. Orientasi Dinamis pada `JustSeparator`

Garis pembatas tata letak (`JustSeparator`) dapat diatur agar bertindak responsif dengan melewatkan parameter `direction: null`:

- Jika orientasi responsif aktif, separator akan membaca lebar layar.
- Jika lebar layar berada di atas batas breakpoint responsif (default: `640.0` px), separator akan dirender secara horizontal.
- Begitu lebar layar turun di bawah breakpoint tersebut, separator secara otomatis membalik orientasinya menjadi vertikal, sangat ideal untuk memisahkan kolom input form yang bertumpuk pada tampilan mobile.
