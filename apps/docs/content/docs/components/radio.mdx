# Radio

Komponen `JustRadio` dan `JustRadioGroup` digunakan untuk menyajikan sekumpulan opsi yang saling eksklusif, di mana pengguna hanya dapat memilih satu opsi saja dalam satu waktu. Komponen ini dirancang independen, memiliki animasi transisi yang mulus, serta mendukung penataan tata letak horizontal maupun vertikal.

---

## Deskripsi

- **`JustRadio`**: Tombol pilihan tunggal berbentuk lingkaran dasar. Dilengkapi dengan label pendamping dan mendukung animasi pembesaran titik tengah secara radial.
- **`JustRadioGroup`**: Kontainer pengelompokan yang mengelola pilihan aktif dari sekumpulan opsi radio (`JustRadioOption`). Grup ini secara otomatis mengatur pergeseran nilai terpilih dan menyusun tata letak opsi secara fleksibel (vertikal atau horizontal).

---

## Usage

### Basic Usage

Contoh penggunaan dasar `JustRadioGroup` untuk memilih satu jenis kelamin:

```dart
import 'package:flutter/material.dart';
import 'package:just_ui_core/just_ui_core.dart';
import 'package:just_ui_tokens/just_ui_tokens.dart';

class RadioBasicDemo extends StatefulWidget {
  const RadioBasicDemo({super.key});

  @override
  State<RadioBasicDemo> createState() => _RadioBasicDemoState();
}

class _RadioBasicDemoState extends State<RadioBasicDemo> {
  String? _selectedGender;

  @override
  Widget build(BuildContext context) {
    return JustRadioGroup<String>(
      value: _selectedGender,
      direction: Axis.horizontal,
      spacing: context.justSpacing.md,
      options: const [
        JustRadioOption(value: 'L', label: Text('Laki-laki')),
        JustRadioOption(value: 'P', label: Text('Perempuan')),
      ],
      onChanged: (val) {
        setState(() {
          _selectedGender = val;
        });
      },
    );
  }
}
```

### Advanced Usage

Contoh penggunaan tingkat lanjut menggunakan tipe data model objek kustom untuk memilih paket berlangganan dengan deskripsi tambahan di bawah label:

```dart
import 'package:flutter/material.dart';
import 'package:just_ui_core/just_ui_core.dart';
import 'package:just_ui_tokens/just_ui_tokens.dart';

class SubscriptionPlan {
  final String id;
  final String title;
  final String price;

  const SubscriptionPlan({required this.id, required this.title, required this.price});
}

class RadioAdvancedDemo extends StatefulWidget {
  const RadioAdvancedDemo({super.key});

  @override
  State<RadioAdvancedDemo> createState() => _RadioAdvancedDemoState();
}

class _RadioAdvancedDemoState extends State<RadioAdvancedDemo> {
  static const List<SubscriptionPlan> _plans = [
    SubscriptionPlan(id: 'free', title: 'Paket Gratis', price: 'Rp 0 / bulan'),
    SubscriptionPlan(id: 'pro', title: 'Paket Pro', price: 'Rp 49.000 / bulan'),
    SubscriptionPlan(id: 'biz', title: 'Paket Bisnis', price: 'Rp 149.000 / bulan'),
  ];

  SubscriptionPlan? _selectedPlan = _plans[0];

  @override
  Widget build(BuildContext context) {
    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      spacing: context.justSpacing.sm,
      children: [
        Text('Pilih Paket Anda:', style: context.justTypo.headingSm),
        JustRadioGroup<SubscriptionPlan>(
          value: _selectedPlan,
          direction: Axis.vertical,
          spacing: context.justSpacing.sm,
          options: _plans.map((plan) {
            return JustRadioOption<SubscriptionPlan>(
              value: plan,
              label: Column(
                crossAxisAlignment: CrossAxisAlignment.start,
                children: [
                  Text(plan.title, style: context.justTypo.bodyMd),
                  Text(
                    plan.price,
                    style: context.justTypo.caption.copyWith(
                      color: context.justColors.textSecondary,
                    ),
                  ),
                ],
              ),
            );
          }).toList(),
          onChanged: (val) {
            setState(() {
              _selectedPlan = val;
            });
          },
        ),
      ],
    );
  }
}
```

## API Reference (Props)

### JustRadio

| Properti     | Tipe Data          | Nilai Bawaan (Default) | Deskripsi                                                                                                |
| :----------- | :----------------- | :--------------------- | :------------------------------------------------------------------------------------------------------- |
| `value`      | `T`                | _Wajib (Required)_     | Nilai unik untuk opsi radio ini.                                                                         |
| `groupValue` | `T?`               | _Wajib (Required)_     | Nilai aktif grup radio yang saat ini terpilih. Jika `value == groupValue`, radio dalam keadaan terpilih. |
| `onChanged`  | `ValueChanged<T>?` | _Wajib (Required)_     | Callback yang dipicu saat opsi radio ini dipilih.                                                        |
| `label`      | `Widget?`          | `null`                 | Widget label (biasanya teks) di sebelah kanan lingkaran radio.                                           |
| `isDisabled` | `bool`             | `false`                | Menonaktifkan pilihan jika diatur ke `true`.                                                             |
| `style`      | `JustRadioStyle?`  | `null`                 | Kustomisasi gaya desain radio.                                                                           |
| `focusNode`  | `FocusNode?`       | `null`                 | Node fokus untuk melacak navigasi keyboard.                                                              |

### JustRadioGroup

| Properti    | Tipe Data                  | Nilai Bawaan (Default) | Deskripsi                                                         |
| :---------- | :------------------------- | :--------------------- | :---------------------------------------------------------------- |
| `options`   | `List<JustRadioOption<T>>` | _Wajib (Required)_     | Daftar opsi radio yang tersedia di dalam kelompok.                |
| `value`     | `T?`                       | `null`                 | Nilai dari opsi radio yang saat ini terpilih dalam grup.          |
| `onChanged` | `ValueChanged<T>?`         | _Wajib (Required)_     | Callback global grup saat salah satu opsi dipilih.                |
| `direction` | `Axis`                     | `.vertical`            | Arah perataan opsi di dalam grup: `.vertical` atau `.horizontal`. |
| `spacing`   | `double?`                  | `null`                 | Jarak pemisah antar opsi radio di dalam grup.                     |
| `style`     | `JustRadioStyle?`          | `null`                 | Gaya desain default untuk seluruh opsi radio di dalam grup.       |

## Theming & Accessibility

### Animasi Gambar Radial (`_RadioDotPainter`)

Untuk menyajikan pengalaman transisi yang organik, titik tengah lingkaran radio tidak hanya muncul seketika:

- **Radial Expansion**: Saat opsi dipilih, bagian tengah lingkaran (`_RadioDotPainter`) digambar secara bertahap membesar secara radial dari pusat lingkaran keluar menuju batas aman border menggunakan pengontrol animasi `AnimationController` bawaan.
- Animasi ini ditarik langsung di atas kanvas koordinat piksel untuk performa rendering tinggi bebas lag.

### Visual Presets

Gaya visual tombol radio menyesuaikan dengan preset tema aktif:

- **Default Preset**:
  - Tombol berbentuk lingkaran halus dengan border dinamis yang bertransisi warna menjadi warna primer ketika terpilih.
  - Memiliki pendaran bayangan melingkar yang lembut ketika berada dalam kondisi fokus (_focused_).

- **Neobrutalism Preset**:
  - Lingkaran luar dipaksa memiliki border hitam pekat (`colors.textPrimary`) setebal `2.5` di semua status (hover, focused, terpilih).
  - Titik tengah lingkaran saat terpilih berwarna hitam pekat (`colors.textPrimary`) untuk mempertahankan nuansa neobrutalisme klasik.
  - Bypass penyesuaian kontras HSL dinamis pada warna border terpilih.

### Accessibility (WCAG AA Compliance)

1. **Target Sentuh**:
   Sama seperti elemen formulir lainnya, seluruh baris opsi (lingkaran radio + teks label pendamping) dibungkus secara internal untuk memastikan target sentuh interaktif minimal **48x48px** sesuai standar WCAG AA.
2. **Navigasi Keyboard Bawaan**:
   Mendukung fitur keyboard traversal bawaan secara penuh. Pengguna dapat berpindah fokus antar pilihan menggunakan tombol panah keyboard (navigasi logis di dalam grup) dan menekan tombol **Enter** atau **Spasi** (_Space_) untuk memilih opsi aktif.
3. **Deskripsi Semantik**:
   Setiap opsi radio dibaca oleh pembaca layar lengkap dengan nomor urutannya dan total pilihan di dalam grup (misalnya: "Pilihan 1 dari 3, Radio Button") untuk memudahkan keterbacaan oleh tunanetra.
