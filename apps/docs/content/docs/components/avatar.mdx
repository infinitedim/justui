# Avatar

Komponen `JustAvatar` dan `JustAvatarGroup` digunakan untuk merepresentasikan pengguna atau entitas secara visual. Komponen ini dirancang dengan mekanisme fallback otomatis yang andal (menggunakan inisial nama atau lukisan vektor kustom jika gambar gagal dimuat) serta algoritma warna inisial yang konsisten.

---

## Deskripsi

- **`JustAvatar`**: Elemen foto profil tunggal berbentuk bulat atau persegi bersudut. Mendukung pemuatan gambar jarak jauh, inisial teks otomatis, ikon alternatif, dan indikator status aktivitas (seperti online/offline).
- **`JustAvatarGroup`**: Kontainer untuk menggabungkan beberapa avatar secara bertumpuk horizontal dengan batasan jumlah tampilan maksimum dan lencana jumlah sisa otomatis (`+X`).

---

## Usage

### Basic Usage

Contoh penggunaan dasar `JustAvatar` dengan URL gambar, inisial nama, maupun ikon:

```dart
import 'package:flutter/material.dart';
import 'package:just_ui_core/just_ui_core.dart';
import 'package:just_ui_tokens/just_ui_tokens.dart';

Widget buildBasicAvatars(BuildContext context) {
  return Row(
    spacing: context.justSpacing.md,
    children: [
      // Avatar dengan URL Gambar
      JustAvatar(
        imageUrl: 'https://images.unsplash.com/photo-1534528741775-53994a69daeb',
        name: 'Sara Wijaya',
      ),

      // Fallback ke Inisial Nama (Menghasilkan warna background konsisten)
      JustAvatar(
        name: 'Budi Santoso',
      ),

      // Fallback ke Ikon
      JustAvatar(
        icon: Icons.group_outlined,
        name: 'Grup Pengembang',
      ),
    ],
  );
}
```

### Advanced Usage

Contoh penggunaan tingkat lanjut yang menunjukkan status aktivitas, bentuk persegi bersudut (_square shape_), dan pengelompokan avatar bertumpuk (_Avatar Group_):

```dart
import 'package:flutter/material.dart';
import 'package:just_ui_core/just_ui_core.dart';
import 'package:just_ui_tokens/just_ui_tokens.dart';

Widget buildAdvancedAvatars(BuildContext context) {
  return Column(
    spacing: context.justSpacing.lg,
    children: [
      // Avatar Kotak dengan Status Online
      JustAvatar(
        name: 'Rian Hidayat',
        shape: JustAvatarShape.square,
        size: JustAvatarSize.lg,
        statusDot: JustAvatarStatus.online,
      ),

      // Pengelompokan Avatar (Avatar Group) dengan Maksimal Tampilan
      JustAvatarGroup(
        avatars: [
          JustAvatar(name: 'Ahmad Faiz'),
          JustAvatar(name: 'Budi Santoso'),
          JustAvatar(name: 'Citra Dewi'),
          JustAvatar(name: 'Dedi Setiadi'),
        ],
        maxDisplay: 3, // Menampilkan 3 avatar, sisanya (+1) sebagai lencana angka
        size: JustAvatarSize.md,
        overlap: 10.0, // Jarak tumpang-tindih horizontal antar avatar
      ),
    ],
  );
}
```

## API Reference (Props)

### JustAvatar

| Properti    | Tipe Data           | Nilai Bawaan (Default) | Deskripsi                                                                                                                  |
| :---------- | :------------------ | :--------------------- | :------------------------------------------------------------------------------------------------------------------------- |
| `imageUrl`  | `String?`           | `null`                 | URL gambar profil pengguna. Jika gagal memuat, sistem akan beralih ke fallback berikutnya.                                 |
| `name`      | `String?`           | `null`                 | Nama pengguna. Digunakan untuk menghasilkan inisial teks otomatis dan kalkulasi warna latar belakang.                      |
| `icon`      | `IconData?`         | `null`                 | Ikon alternatif jika gambar gagal dimuat dan nama pengguna bernilai kosong.                                                |
| `size`      | `JustAvatarSize`    | `.md`                  | Ukuran dimensi avatar: `.xs` (24px), `.sm` (32px), `.md` (40px), `.lg` (48px), `.xl` (64px), `.xxl` (96px).                |
| `shape`     | `JustAvatarShape`   | `.circle`              | Bentuk geometri avatar: `.circle` (bulat penuh) atau `.square` (persegi dengan sudut tumpul `radius.xl`).                  |
| `statusDot` | `JustAvatarStatus?` | `null`                 | Titik indikator aktivitas pengguna di pojok bawah: `online` (hijau), `offline` (abu-abu), `away` (kuning), `busy` (merah). |
| `onTap`     | `VoidCallback?`     | `null`                 | Callback interaktif saat avatar diketuk.                                                                                   |

### JustAvatarGroup

| Properti     | Tipe Data          | Nilai Bawaan (Default) | Deskripsi                                                                                                          |
| :----------- | :----------------- | :--------------------- | :----------------------------------------------------------------------------------------------------------------- |
| `avatars`    | `List<JustAvatar>` | _Wajib (Required)_     | Daftar avatar pengguna yang akan digabungkan secara bertumpuk.                                                     |
| `maxDisplay` | `int`              | `3`                    | Batas jumlah avatar maksimum yang akan ditampilkan secara utuh sebelum sisanya digantikan oleh lencana angka `+X`. |
| `overlap`    | `double`           | `8.0`                  | Nilai jarak tumpang-tindih (overlap) horizontal antar avatar dalam satuan piksel.                                  |
| `size`       | `JustAvatarSize`   | `.md`                  | Ukuran dimensi untuk seluruh avatar di dalam kelompok.                                                             |

## Theming & Accessibility

### Mekanisme Fallback & Keamanan Rendering

JustUI menjamin komponen `JustAvatar` tidak akan memicu kesalahan visual layar (_broken layout_) jika tautan gambar rusak atau sedang dalam kondisi offline:

1. **Unduhan Gambar Gagal / Menunggu**:
   Saat gambar sedang dimuat atau gagal diunduh, sistem beralih menggunakan fungsi `_generateInitials` untuk mengambil huruf awal dari properti `name` (misalnya: "Budi Santoso" menghasilkan inisial "BS").
2. **Kalkulasi Warna Deterministik**:
   Warna latar belakang inisial nama ditentukan secara konsisten menggunakan kode hash nama pengguna:
   ```text
   Indeks Warna = name.hashCode.abs() % panjang_daftar_warna_tema
   ```
   Hal ini menjamin bahwa setiap pengguna dengan nama yang sama akan selalu mendapatkan warna latar belakang avatar yang konsisten setiap kali aplikasi dimuat ulang.
3. **Vektor Silhouette Kanvas (`PersonFallbackPainter`)**:
   Jika URL gambar rusak dan properti `name` kosong, sistem akan langsung melukis siluet tubuh dan kepala manusia secara manual menggunakan `CustomPainter` bawaan Flutter. Hal ini membebaskan JustUI dari ketergantungan paket ikon pihak ketiga (sehingga ukuran aplikasi tetap kecil dan aman).

### Konstruksi Stack Terbalik di `JustAvatarGroup`

Pada `JustAvatarGroup`, komponen dirender di dalam `Stack` dengan urutan terbalik (indeks akhir diletakkan di bawah indeks awal). Urutan ini memastikan:

- Avatar pertama selalu berada di lapisan teratas (visual tumpukan maju).
- Setiap avatar di sekelilingnya memiliki batas luar melingkar berwarna putih kontras tinggi (_visual cutout_). Batas ini memotong bayangan avatar di bawahnya, menjaga visual tetap bersih tanpa bayangan bertumpuk kasar.

### Accessibility (WCAG AA Compliance)

1. **Kontras Label Inisial**:
   Teks inisial nama yang muncul pada avatar dipastikan menggunakan warna kontras tinggi terhadap latar belakang warna deterministiknya.
2. **Deskripsi Semantik**:
   Bila avatar memiliki `statusDot` (misalnya: `JustAvatarStatus.online`), pembaca layar akan membacakan status tersebut sebagai teks semantik deskriptif (contoh: "Budi Santoso - Aktif") untuk aksesibilitas tunanetra.
