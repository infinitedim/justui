# Pendahuluan

**JustUI** adalah sekumpulan komponen UI Flutter yang dirancang dengan estetika premium, aksesibilitas tinggi, dan performa maksimal. JustUI tidak diinstal sebagai package pihak ketiga melainkan menggunakan alur kerja **copy-paste** yang terinspirasi dari shadcn/ui.

## Mengapa JustUI?

1. **Zero-Dependency Footprint**: Komponen JustUI tidak mengandalkan package pub.dev pihak ketiga selain bawaan Flutter SDK.
2. **Kustomisasi Penuh**: Karena kode sumber komponen berada langsung di proyek Anda, Anda bebas mengubah parameter, visual, maupun logikanya tanpa hambatan.
3. **Desain Modern**: Menyediakan preset visual tingkat lanjut, termasuk gaya **Neobrutalism** dengan kontras tajam, bayangan solid, dan transisi halus.

## Langkah Selanjutnya

Mari kita siapkan CLI tool dan lakukan inisialisasi pada proyek Anda melalui halaman [Instalasi](/docs/installation).
