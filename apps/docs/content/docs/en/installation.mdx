# Installation

JustUI provides a fast, standalone command-line tool (CLI) written in Rust to copy components into your Flutter project quickly.

## Step 1: Install the JustUI CLI

### Via Install Script (Recommended)

All binaries downloaded via our install scripts are cryptographically verified against published SHA-256 checksums before installation.

```bash
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/infinitedim/justui/main/packages/cli/install/install.sh | sh

# Windows (PowerShell)
irm https://raw.githubusercontent.com/infinitedim/justui/main/packages/cli/install/install.ps1 | iex
```

### Build from Source (Zero-Trust)

If you prefer building directly from source:

```bash
git clone https://github.com/infinitedim/justui.git
cd justui/packages/cli
cargo install --path .
```

Verify the installation:

```bash
justui --version
```

## Step 2: Initialize Your Project

Run the following command in the root directory of your Flutter project:

```bash
justui init
```

This wizard will create `justui.config.yaml` and bootstrap your theme file at `lib/theme/just_theme.dart`. You will also be prompted to choose a visual preset (`default` or `neobrutalism`).

## Step 3: Adding Components

To add a new component (for example, a button), use the `add` command:

```bash
justui add button
```

The component and its dependencies will be automatically copied to your configured components directory (default: `lib/ui/button`).
