# Bottom Navigation

`JustBottomNav` is the main navigation component for mobile interfaces, positioned at the bottom of the screen. It is designed to simplify switching between main app pages by supporting a minimum of 3 to a maximum of 5 navigation items, and offering fixed, dynamically shifting, and floating style variants.

## Usage

### Basic

Basic usage example of `JustBottomNav` with the default fixed width style for 3 main menus.

```dart
import 'package:material_ui/material_ui.dart';
import 'package:your_app/core/just_ui_core.dart';

class BasicBottomNavExample extends StatefulWidget {
  const BasicBottomNavExample({super.key});

  @override
  State<BasicBottomNavExample> createState() => _BasicBottomNavExampleState();
}

class _BasicBottomNavExampleState extends State<BasicBottomNavExample> {
  int _currentIndex = 0;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      bottomNavigationBar: JustBottomNav(
        selectedIndex: _currentIndex,
        onItemSelected: (index) {
          setState(() {
            _currentIndex = index;
          });
        },
        items: const [
          JustBottomNavItem(
            label: 'Home',
            icon: Icon(Icons.home_outlined),
            activeIcon: Icon(Icons.home),
          ),
          JustBottomNavItem(
            label: 'Search',
            icon: Icon(Icons.search),
          ),
          JustBottomNavItem(
            label: 'Profile',
            icon: Icon(Icons.person_outline),
            activeIcon: Icon(Icons.person),
          ),
        ],
      ),
    );
  }
}
```

### Advanced

Advanced usage example using the floating variant, haptic feedback, and icon alignment.

```dart
import 'package:material_ui/material_ui.dart';
import 'package:flutter/services.dart';
import 'package:your_app/core/just_ui_core.dart';

class AdvancedBottomNavExample extends StatefulWidget {
  const AdvancedBottomNavExample({super.key});

  @override
  State<AdvancedBottomNavExample> createState() => _AdvancedBottomNavExampleState();
}

class _AdvancedBottomNavExampleState extends State<AdvancedBottomNavExample> {
  int _currentIndex = 0;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      bottomNavigationBar: Padding(
        padding: const .all(16.0),
        child: JustBottomNav(
          selectedIndex: _currentIndex,
          variant: .floating,
          showLabels: true,
          onItemSelected: (index) {
            HapticFeedback.lightImpact(); // Provides light haptic vibration
            setState(() {
              _currentIndex = index;
            });
          },
          items: const [
            JustBottomNavItem(
              label: 'Home',
              icon: Icon(Icons.home_outlined),
              activeIcon: Icon(Icons.home),
            ),
            JustBottomNavItem(
              label: 'Messages',
              icon: Icon(Icons.chat_bubble_outline),
              activeIcon: Icon(Icons.chat_bubble),
            ),
            JustBottomNavItem(
              label: 'Cart',
              icon: Icon(Icons.shopping_cart_outlined),
              activeIcon: Icon(Icons.shopping_cart),
            ),
            JustBottomNavItem(
              label: 'Account',
              icon: Icon(Icons.account_circle_outlined),
              activeIcon: Icon(Icons.account_circle),
            ),
          ],
        ),
      ),
    );
  }
}
```

## API Reference (Props)

### JustBottomNav

| Property         | Data Type                 | Default Value                | Description                                                                                                                                                                                                 |
| ---------------- | ------------------------- | ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `items`          | `List<JustBottomNavItem>` | _Required_                   | Set of bottom navigation destination menus (must contain between 3 and 5 items).                                                                                                                            |
| `selectedIndex`  | `int`                     | `0`                          | The currently active selected navigation item index.                                                                                                                                                        |
| `onItemSelected` | `ValueChanged<int>?`      | `null`                       | Callback triggered when the user taps one of the menu items.                                                                                                                                                |
| `variant`        | `JustBottomNavVariant`    | `JustBottomNavVariant.fixed` | Bottom navigation visual style: `.fixed` (fixed width), `.shifting` (expanding transition effect when selected, hides inactive text), or `.floating` (freely floating with a soft shadow above the screen). |
| `showLabels`     | `bool`                    | `true`                       | Determines whether the label text below icons is visually displayed.                                                                                                                                        |
| `style`          | `JustBottomNavStyle?`     | `null`                       | Per-instance style overrides for height, padding, colors, borders, indicator bar, typography, and motion.                                                                                                   |
| `semanticsLabel` | `String?`                 | `null`                       | Optional accessible label announced for the bottom navigation container.                                                                                                                                    |

### JustBottomNavItem

| Property     | Data Type | Default Value | Description                                                    |
| ------------ | --------- | ------------- | -------------------------------------------------------------- |
| `label`      | `String`  | _Required_    | Navigation menu title text.                                    |
| `icon`       | `Widget`  | _Required_    | Icon displayed when the menu is inactive.                      |
| `activeIcon` | `Widget?` | `null`        | Alternative icon displayed when the menu is actively selected. |

### JustBottomNavStyle

`JustBottomNavStyle` supports per-instance overrides for bar dimensions, colors, typography, and active state styling, including:

| Property               | Data Type | Default Value | Description                                                                                                                                   |
| ---------------------- | --------- | ------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `borderColor`          | `Color?`  | `null`        | Custom border color for the navigation bar container (defaults to `colors.textPrimary` in Neobrutalism or `colors.borderDefault` in Default). |
| `activeIndicatorColor` | `Color?`  | `null`        | Custom color for the compact active indicator bar beneath the selected item (defaults to `activeColor`).                                      |
| `showActiveIndicator`  | `bool?`   | `null`        | Whether to render a compact active indicator bar beneath the selected item (defaults to `false`).                                             |

## Theming & Accessibility

### Preset & Style Customization

- **Default Style**: Uses `colors.elevated` as the bar background, a `colors.borderDefault` top divider (or full pill outline on `.floating` with `BorderRadius.all(radius.full)`), and optional compact rounded active indicator bar via `JustBottomNavStyle.showActiveIndicator` and `activeIndicatorColor`.
- **Neobrutalism Style**: Applies a crisp `colors.textPrimary` border (`presetTokens.borderWidth`), sharp `BorderRadius.zero` corners across the bar (including `.floating`), focus ring, and active indicator bar, plus a solid offset shadow on `.floating`. You can override the border color with `JustBottomNavStyle.borderColor`.

### WCAG AA Compliance

- **Item Count Limit (Touch Area)**: This component enforces an assertion on `items` to keep the destination count between `3` and `5`, preserving balanced widths and >= 48x48 touch targets on mobile screens.
- **Visible Focus Indicator & Single-Label Semantics**: Each item renders a visible keyboard `FocusIndicator` when focused via keyboard navigation and wraps its content in `Semantics(label: item.label, selected: isSelected, button: true, excludeSemantics: true)` so screen readers announce a single clean label without duplicating child text nodes. The bar container exposes `Semantics(container: true, explicitChildNodes: true, label: semanticsLabel)`. Active text and icon contrast meets >= 4.5:1.
- **Reduced Motion**: Respects `MediaQuery.disableAnimationsOf(context)` and `animations.resolve(context)`, collapsing icon, label, shifting flex, and active indicator transition durations to `Duration.zero` when reduced motion is enabled.
