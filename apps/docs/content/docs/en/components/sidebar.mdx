# Sidebar

`JustSidebar` is a robust and responsive side navigation component for desktop, tablet, and administrative dashboard interfaces. This component supports recursive nested routing, collapsed status, and automatically adjusts its layout width independently when detecting small screens.

## Usage

### Basic

The following is a basic usage example of `JustSidebar` for a single-level navigation menu.

```dart
import 'package:material_ui/material_ui.dart';
import 'package:your_app/core/just_ui_core.dart';

class BasicSidebarExample extends StatefulWidget {
  const BasicSidebarExample({super.key});

  @override
  State<BasicSidebarExample> createState() => _BasicSidebarExampleState();
}

class _BasicSidebarExampleState extends State<BasicSidebarExample> {
  int _selectedIdx = 0;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Row(
        children: [
          JustSidebar(
            selectedIndex: _selectedIdx,
            onItemSelected: (index) {
              setState(() {
                _selectedIdx = index;
              });
            },
            items: const [
              JustSidebarItem(
                label: 'Dashboard',
                icon: Icon(Icons.dashboard_outlined),
              ),
              JustSidebarItem(
                label: 'Transactions',
                icon: Icon(Icons.receipt_long),
              ),
              JustSidebarItem(
                label: 'Settings',
                icon: Icon(Icons.settings),
              ),
            ],
          ),
          const VerticalDivider(width: 1.0),
          Expanded(
            child: Center(
              child: Text('Page Content #$_selectedIdx'),
            ),
          ),
        ],
      ),
    );
  }
}
```

### Advanced

Advanced usage example with nested (recursive) menus, user profile header, logout footer, and collapsed status option.

```dart
import 'package:material_ui/material_ui.dart';
import 'package:your_app/core/just_ui_core.dart';

class AdvancedSidebarExample extends StatefulWidget {
  const AdvancedSidebarExample({super.key});

  @override
  State<AdvancedSidebarExample> createState() => _AdvancedSidebarExampleState();
}

class _AdvancedSidebarExampleState extends State<AdvancedSidebarExample> {
  int _selectedIdx = 0;
  bool _isSidebarCollapsed = false;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Row(
        children: [
          JustSidebar(
            isCollapsed: _isSidebarCollapsed,
            variant: .inset,
            header: Padding(
              padding: const .all(16.0),
              child: Row(
                children: [
                  const JustAvatar(name: 'Admin JustUI', size: .md),
                  if (!_isSidebarCollapsed) ...[
                    const SizedBox(width: 12.0),
                    const Expanded(
                      child: Text(
                        'Administrator',
                        style: TextStyle(fontWeight: .bold),
                        overflow: .ellipsis,
                      ),
                    ),
                  ],
                ],
              ),
            ),
            footer: JustIconButton(
              icon: Icon(_isSidebarCollapsed ? Icons.chevron_right : Icons.chevron_left),
              tooltip: _isSidebarCollapsed ? 'Open Sidebar' : 'Close Sidebar',
              onPressed: () {
                setState(() {
                  _isSidebarCollapsed = !_isSidebarCollapsed;
                });
              },
            ),
            selectedIndex: _selectedIdx,
            onItemSelected: (index) {
              setState(() {
                _selectedIdx = index;
              });
            },
            items: [
              const JustSidebarItem(
                label: 'Dashboard',
                icon: Icon(Icons.home),
              ),
              JustSidebarItem(
                label: 'Data Management',
                icon: const Icon(Icons.folder_open),
                children: [
                  JustSidebarItem(
                    label: 'Client List',
                    icon: const Icon(Icons.people_outline),
                    onTap: () => _navigateTo('/clients'),
                  ),
                  JustSidebarItem(
                    label: 'Permissions',
                    icon: const Icon(Icons.lock_outline),
                    onTap: () => _navigateTo('/permissions'),
                  ),
                ],
              ),
              const JustSidebarItem(
                label: 'Analytics Reports',
                icon: Icon(Icons.analytics),
              ),
            ],
          ),
          const VerticalDivider(width: 1.0),
          Expanded(
            child: Center(
              child: Text('Active page #$_selectedIdx'),
            ),
          ),
        ],
      ),
    );
  }

  void _navigateTo(String route) {
    print('Navigating to: $route');
  }
}
```

## API Reference (Props)

### JustSidebar

| Property         | Type                    | Default                       | Description                                                                                                                              |
| ---------------- | ----------------------- | ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `items`          | `List<JustSidebarItem>` | _Required_                    | Navigation menu item array that can branch recursively (nested).                                                                         |
| `selectedIndex`  | `int`                   | `0`                           | Index of the currently active sidebar item.                                                                                              |
| `onItemSelected` | `ValueChanged<int>?`    | `null`                        | Callback triggered when a navigation item is tapped.                                                                                     |
| `header`         | `Widget?`               | `null`                        | Top area widget (e.g., company logo or user profile summary).                                                                            |
| `footer`         | `Widget?`               | `null`                        | Bottom area widget (e.g., logout button or collapse toggle).                                                                             |
| `width`          | `double`                | `260.0`                       | Panel width when in fully open state.                                                                                                    |
| `collapsedWidth` | `double`                | `68.0`                        | Minimum panel width when in collapsed state.                                                                                             |
| `isCollapsed`    | `bool`                  | `false`                       | Active collapse status of the panel.                                                                                                     |
| `autoCollapse`   | `bool`                  | `true`                        | Whether the sidebar automatically collapses on viewports at or below `JustBreakpoints.md`. Set to `false` for embedded or narrow panels. |
| `variant`        | `JustSidebarVariant`    | `JustSidebarVariant.default_` | Layout style: `.default_` (edge-attached), `.floating` (free-floating with shadow), or `.inset` (isolated within page frame).            |
| `style`          | `JustSidebarStyle?`     | `null`                        | Per-instance visual overrides for panel borders, radius, selected item colors, spacing, padding, and typography.                         |
| `semanticsLabel` | `String?`               | `null`                        | Optional accessible label announced for the sidebar navigation container.                                                                |

### JustSidebarItem

| Property   | Type                     | Default    | Description                                        |
| ---------- | ------------------------ | ---------- | -------------------------------------------------- |
| `label`    | `String`                 | _Required_ | Navigation menu item text label.                   |
| `icon`     | `Widget`                 | _Required_ | Visual icon accompanying the menu text.            |
| `onTap`    | `VoidCallback?`          | `null`     | Optional action callback when item is tapped.      |
| `children` | `List<JustSidebarItem>?` | `null`     | Child submenu list for nested foldable menu items. |

### JustSidebarStyle

`JustSidebarStyle` lets you override panel and item presentation per instance, including:

| Property                  | Type            | Default | Description                                                                                                                        |
| ------------------------- | --------------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `borderColor`             | `Color?`        | `null`  | Custom border color for the sidebar panel (defaults to `colors.textPrimary` in Neobrutalism or `colors.borderDefault` in Default). |
| `borderRadius`            | `BorderRadius?` | `null`  | Custom border radius for the sidebar panel.                                                                                        |
| `selectedBackgroundColor` | `Color?`        | `null`  | Custom background color for the active selected sidebar item.                                                                      |
| `selectedForegroundColor` | `Color?`        | `null`  | Custom foreground (icon and label) color for the active selected sidebar item.                                                     |
| `itemSpacing`             | `double?`       | `null`  | Custom vertical spacing between sidebar items (defaults to `0.0`).                                                                 |

## Theming & Accessibility

### Preset & Style Customization

- **Default Style**: Panel width transitions use `AnimationController` driven by `animations.normal` (`animations.resolve(context)`). Corner rounding follows `radius.xl` on `.floating` and `radius.lg` on `.inset`. You can customize panel borders, radius, active item background/foreground colors, and vertical spacing via `JustSidebarStyle`.
- **Neobrutalism Style**: Forces crisp `colors.textPrimary` borders (`presetTokens.borderWidth`), sharp `BorderRadius.zero` panel corners, and solid offset shadows on `.floating` and `.inset` variants.

### Auto-Collapse Responsive, Unbounded Height & Folder Animation

- **Auto-Collapse**: By default (`autoCollapse: true`), when the viewport width is at or below `JustBreakpoints.md` (768px), the sidebar automatically collapses to `collapsedWidth` (`68.0` px) so page content stays readable on narrow screens. Set `autoCollapse: false` when embedding `JustSidebar` inside compact previews, split panels, or narrow containers where it should remain expanded.
- **Unbounded Height Safety**: `JustSidebar` inspects `constraints.hasBoundedHeight` via `LayoutBuilder`. When placed inside a bounded vertical container it fills available height and scrolls items in `Expanded(child: SingleChildScrollView(...))`; when placed inside an unbounded layout it sizes cleanly to its content (`MainAxisSize.min`) without throwing layout errors.
- **Recursive Folder**: Nested child branches are indented by `depth * 16.0` px at each level with vertical folding via `SizeTransition`.
- **Tooltip Balloon**: When the sidebar is collapsed, hovering an item displays its label in a floating `JustTooltipOverlay` so icon-only navigation remains clear.

### WCAG AA Compliance

- **Visible Focus Indicator & Deduplicated Semantics**: Both leaf items and collapsible folder headers render a visible keyboard `FocusIndicator` when focused and wrap their content in `Semantics(..., excludeSemantics: true)` (exposing `button: true`, `selected` or `expanded`, `enabled`, and `label`) so screen readers do not announce duplicate child text. The outer panel exposes `Semantics(container: true, explicitChildNodes: true, label: semanticsLabel)`.
- **Collapsed Folder Focus & Semantics Exclusion**: Nested children inside a collapsed folder are wrapped in `ExcludeFocus` and `ExcludeSemantics` (`excluding: !_isExpanded`), keeping hidden submenu items out of keyboard focus traversal and screen reader trees until expanded.
- **Reduced Motion & Contrast**: Both sidebar collapse and folder expand controllers resolve `animations.resolve(context)` and snap directly to target values when duration is `Duration.zero`. Text and background colors meet >= 4.5:1 contrast.
