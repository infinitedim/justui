# Scroll Area

`JustScrollArea` is a high-performance scrolling container that replaces the operating system's native scrollbar with a custom scrollbar that adheres to the design system's aesthetics. This component supports transparent fade edge effects at the top and bottom boundaries of the scroll, an automatic back-to-top button, and infinite scroll data loading triggers.

## Usage

### Basic

The following is a basic usage example of `JustScrollArea` for wrapping a simple scrollable content list.

```dart
import 'package:material_ui/material_ui.dart';
import 'package:your_app/core/just_ui_core.dart';

class BasicScrollAreaExample extends StatelessWidget {
  const BasicScrollAreaExample({super.key});

  @override
  Widget build(BuildContext context) {
    return Container(
      height: 300.0,
      decoration: BoxDecoration(
        border: Border.all(color: context.justColors.borderDefault),
        borderRadius: .all(context.justRadius.md),
      ),
      child: JustScrollArea(
        child: Column(
          children: List.generate(
            50,
            (index) => ListTile(
              title: Text('Item #$index'),
            ),
          ),
        ),
      ),
    );
  }
}
```

### Advanced

Advanced usage example with edge fading using `ShaderMask`, automatic back-to-top button, keyboard scrolling, and infinite scroll pagination.

```dart
import 'package:material_ui/material_ui.dart';
import 'package:your_app/core/just_ui_core.dart';

class AdvancedScrollAreaExample extends StatefulWidget {
  const AdvancedScrollAreaExample({super.key});

  @override
  State<AdvancedScrollAreaExample> createState() => _AdvancedScrollAreaExampleState();
}

class _AdvancedScrollAreaExampleState extends State<AdvancedScrollAreaExample> {
  final List<String> _items = List.generate(20, (index) => 'Initial Item #$index');
  bool _isLoadingMore = false;

  void _loadMoreData() async {
    if (_isLoadingMore) return;
    setState(() => _isLoadingMore = true);

    // Network delay simulation
    await Future.delayed(const Duration(seconds: 2));

    setState(() {
      _items.addAll(List.generate(10, (index) => 'Additional Item #${_items.length + index}'));
      _isLoadingMore = false;
    });
  }

  @override
  Widget build(BuildContext context) {
    return Container(
      height: 400.0,
      decoration: BoxDecoration(
        border: Border.all(color: context.justColors.borderDefault),
        borderRadius: .all(context.justRadius.lg),
      ),
      child: JustScrollArea(
        direction: .vertical,
        showScrollbar: true,
        fadeEdges: true,
        fadeMode: .mask,
        scrollToTopButton: true,
        scrollToTopThreshold: 300.0,
        keyboardScrollStep: 60.0,
        onReachBottom: _loadMoreData, // Triggers data load when approaching bottom
        child: ListView.builder(
          shrinkWrap: true,
          physics: const NeverScrollableScrollPhysics(), // Scroll fully controlled by JustScrollArea
          itemCount: _items.length + (_isLoadingMore ? 1 : 0),
          itemBuilder: (context, index) {
            if (index == _items.length) {
              return const Padding(
                padding: .all(16.0),
                child: Center(child: CircularProgressIndicator()),
              );
            }
            return ListTile(title: Text(_items[index]));
          },
        ),
      ),
    );
  }
}
```

## API Reference (Props)

### JustScrollArea

| Property               | Type                   | Default                      | Description                                                                                                     |
| ---------------------- | ---------------------- | ---------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `child`                | `Widget`               | _Required_                   | Child widget containing the scrollable content list.                                                            |
| `direction`            | `Axis`                 | `Axis.vertical`              | Main scroll direction of the container (vertical or horizontal).                                                |
| `showScrollbar`        | `bool`                 | `true`                       | Determines whether the custom JustUI scrollbar is visually displayed.                                           |
| `fadeEdges`            | `bool`                 | `false`                      | If true, applies a transparent gradient effect at the scroll boundary edges (indicating additional content).    |
| `fadeMode`             | `JustScrollFadeMode`   | `JustScrollFadeMode.overlay` | Edge fade technique: `.overlay` or `.mask`.                                                                     |
| `scrollToTopButton`    | `bool`                 | `false`                      | Displays a back-to-top button automatically when scrolled far.                                                  |
| `scrollToTopThreshold` | `double`               | `400.0`                      | Minimum scroll distance threshold (in pixels) to trigger the back-to-top button.                                |
| `onReachBottom`        | `VoidCallback?`        | `null`                       | Callback triggered when scrolling approaches the bottom boundary of the container (useful for infinite scroll). |
| `keyboardScrollStep`   | `double`               | `50.0`                       | Scroll jump distance (in pixels) per arrow key press on the keyboard.                                           |
| `semanticsLabel`       | `String?`              | `null`                       | Optional accessibility label announced for the scrollable container region.                                     |
| `thumbVisibility`      | `bool?`                | `null`                       | Overrides whether the scrollbar thumb always remains visible (defaults to `false`).                             |
| `trackVisibility`      | `bool?`                | `null`                       | Overrides whether the scrollbar track always remains visible (takes effect when `thumbVisibility` is `true`).   |
| `style`                | `JustScrollAreaStyle?` | `null`                       | Per-instance visual overrides for fade edges, scrollbar appearance, focus ring radius, and smooth scroll.       |

### JustScrollAreaStyle

`JustScrollAreaStyle` lets you customize fade edges, scrollbar geometry, visibility, focus indicator radius, and smooth scrolling per instance, including:

| Property                   | Type            | Default | Description                                                                                       |
| -------------------------- | --------------- | ------- | ------------------------------------------------------------------------------------------------- |
| `thumbVisibility`          | `bool?`         | `null`  | Keeps the scrollbar thumb permanently visible when `true`.                                        |
| `trackVisibility`          | `bool?`         | `null`  | Keeps the scrollbar track visible when `true` (active when `thumbVisibility` resolves to `true`). |
| `scrollbarTrackRadius`     | `Radius?`       | `null`  | Corner radius for the scrollbar track (forced to `Radius.zero` under Neobrutalism).               |
| `scrollbarCrossAxisMargin` | `double?`       | `null`  | Cross-axis margin for the scrollbar track (defaults to `0.0`).                                    |
| `focusBorderRadius`        | `BorderRadius?` | `null`  | Corner radius for the keyboard `FocusIndicator` rendered around the scroll area.                  |

## Theming & Accessibility

### Preset & Style Customization

- **Default Style**: The custom scrollbar uses rounded corners (`Radius.circular(3.0)` by default) and soft thumb tinting derived from `colors.textSecondary`, with optional persistent thumb/track visibility via `thumbVisibility`, `trackVisibility`, and `JustScrollAreaStyle`.
- **Neobrutalism Style**: Forces sharp `Radius.zero` corners on both the scrollbar thumb and track (`scrollbarTrackRadius`), matching the crisp geometric preset tokens.

### Keyboard Integration & ShaderMask

- **Desktop Keyboard Navigation**: Binds the container with an internal `FocusNode` handling both `KeyDownEvent` and `KeyRepeatEvent` (holding a key scrolls continuously). `Home` and `End` jump to the start (`0.0`) or end (`maxScrollExtent`), `PageUp` and `PageDown` scroll by one viewport dimension, and directional arrow keys (`ArrowUp`/`ArrowDown` for vertical, `ArrowLeft`/`ArrowRight` for horizontal) step by `keyboardScrollStep`.
- **Edge ShaderMasking**: When `fadeMode` is `JustScrollFadeMode.mask`, a dynamic multi-stop `ShaderMask` alpha gradient prevents text or images from being harshly clipped at the viewport edges.

### WCAG AA Compliance

- **Visible Focus Indicator & Semantics Container**: Renders a visible keyboard `FocusIndicator` around the scrollable area when focused via keyboard (customizable with `JustScrollAreaStyle.focusBorderRadius`), and wraps the region in `Semantics(container: true, label: semanticsLabel)`.
- **Scroll-to-Top Target & Reduced Motion**: The floating scroll-to-top button enforces a minimum `48x48` touch target with its own `FocusIndicator` and semantic label `'Scroll to top'`. When reduced motion is enabled (`animations.resolve(context)` resolves `fast` to `Duration.zero`), keyboard scrolling and scroll-to-top bypass smooth/animated scrolling and jump immediately via `jumpTo`.
