# Icon Button

The `JustIconButton` component is a specialized, compact button tailored for actions represented solely by icons. It enforces strict accessibility standards by requiring a descriptive tooltip for screen readers and assistive technologies.

---

## Description

- **Icon Focus**: Displays a single centered icon without textual labels, maintaining compact spatial proportions.
- **Accessibility Assertion**: Enforces non-null `tooltip` parameter to ensure all icon-only buttons remain accessible to screen readers.
- **Interactive Feedback**: Features built-in press scaling, hover effects, and optional haptic feedback on mobile platforms.
- **Variant Support**: Integrates with JustUI design tokens, supporting ghost, primary, outline, secondary, and destructive styles.

---

## Usage

### Basic Usage

Simple icon button with required tooltip:

```dart
import 'package:flutter/material.dart';
import 'package:just_ui_core/just_ui_core.dart';
import 'package:just_ui_tokens/just_ui_tokens.dart';

Widget buildBasicIconButton(BuildContext context) {
  return JustIconButton(
    icon: const Icon(Icons.share),
    tooltip: 'Share document',
    onPressed: () => print('Share clicked'),
  );
}
```

### Advanced Usage

Icon buttons with size, variant, loading state, and custom styling:

```dart
import 'package:flutter/material.dart';
import 'package:just_ui_core/just_ui_core.dart';
import 'package:just_ui_tokens/just_ui_tokens.dart';

Widget buildAdvancedIconButtons(BuildContext context) {
  return Row(
    spacing: context.justSpacing.md,
    children: [
      // Primary variant
      JustIconButton(
        icon: const Icon(Icons.download),
        tooltip: 'Download file',
        variant: .primary,
        size: .lg,
        onPressed: () => print('Download clicked'),
      ),

      // Destructive variant
      JustIconButton(
        icon: const Icon(Icons.delete_outline),
        tooltip: 'Delete item',
        variant: .destructive,
        size: .md,
        onPressed: () => print('Delete clicked'),
      ),

      // Loading state
      JustIconButton(
        icon: const Icon(Icons.refresh),
        tooltip: 'Refreshing data',
        isLoading: true,
        onPressed: () {},
      ),
    ],
  );
}
```

## API Reference (Props)

### JustIconButton

| Property       | Data Type           | Default Value | Description                                                                            |
| :------------- | :------------------ | :------------ | :------------------------------------------------------------------------------------- |
| `icon`         | `Widget`            | _required_    | The icon widget displayed at the center of the button.                                 |
| `tooltip`      | `String`            | _required_    | Mandatory accessibility description for screen readers and tooltips.                   |
| `onPressed`    | `VoidCallback?`     | _required_    | Callback executed when tapped. Pass null to disable.                                   |
| `variant`      | `JustButtonVariant` | `.ghost`      | Visual style variant (`.ghost`, `.primary`, `.outline`, `.secondary`, `.destructive`). |
| `size`         | `JustButtonSize`    | `.md`         | Physical dimensions (`.xs`, `.sm`, `.md`, `.lg`, `.xl`).                               |
| `isLoading`    | `bool`              | `false`       | When true, renders a loading spinner instead of the icon.                              |
| `isDisabled`   | `bool`              | `false`       | Explicitly disables interactions and applies muted styling.                            |
| `enableHaptic` | `bool?`             | `null`        | Controls haptic vibration on press. Falls back to theme configuration.                 |
| `style`        | `JustButtonStyle?`  | `null`        | Per-instance style overrides for custom backgrounds or borders.                        |

## Accessibility

`JustIconButton` complies with WCAG AA guidelines:

- **Mandatory Tooltip**: Unlike standard text buttons, `tooltip` is required to guarantee that screen readers announce the semantic intent of the action.
- **Minimum Target Size**: With default `.md` sizing, touch dimensions meet or exceed 44x44 points for reliable finger touch interaction.
