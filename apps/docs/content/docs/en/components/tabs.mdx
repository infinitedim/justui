# Tabs

`JustTabs` is a component used to divide content into multiple interconnected view panels. It is designed to maximize Flutter rendering performance by applying lazy loading techniques and active page caching, as well as smooth sliding indicator transitions.

## Usage

### Basic

The following is a basic usage example of `JustTabs` for creating a simple navigation tab.

```dart
import 'package:flutter/widgets.dart';
import 'package:material_ui/material_ui.dart' show Icons;
import 'package:your_app/core/just_ui_core.dart';

class BasicTabsExample extends StatelessWidget {
  const BasicTabsExample({super.key});

  @override
  Widget build(BuildContext context) {
    return JustTabs(
      tabs: [
        JustTab(
          label: 'Profile',
          icon: const Icon(Icons.person),
          content: const Center(child: Text('User Profile Content')),
        ),
        JustTab(
          label: 'Settings',
          icon: const Icon(Icons.settings),
          content: const Center(child: Text('Settings Content')),
        ),
      ],
    );
  }
}
```

### Advanced

Advanced usage example using the `pill` variant, horizontally scrollable tab titles, badge addition, and disabled tabs.

```dart
import 'package:flutter/widgets.dart';
import 'package:material_ui/material_ui.dart' show Icons;
import 'package:your_app/core/just_ui_core.dart';

class AdvancedTabsExample extends StatefulWidget {
  const AdvancedTabsExample({super.key});

  @override
  State<AdvancedTabsExample> createState() => _AdvancedTabsExampleState();
}

class _AdvancedTabsExampleState extends State<AdvancedTabsExample> {
  late final JustTabController _tabController;

  @override
  void initState() {
    super.initState();
    _tabController = JustTabController(length: 4, initialIndex: 0);
  }

  @override
  void dispose() {
    _tabController.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return JustTabs(
      controller: _tabController,
      variant: .pill,
      isScrollable: true,
      tabs: [
        JustTab(
          label: 'Account',
          icon: const Icon(Icons.account_circle),
          content: const AccountSettingsView(),
        ),
        JustTab(
          label: 'Security',
          icon: const Icon(Icons.security),
          content: const SecuritySettingsView(),
          badge: const JustBadge.dot(color: .error),
        ),
        JustTab(
          label: 'Notifications',
          icon: const Icon(Icons.notifications),
          content: const NotificationSettingsView(),
        ),
        JustTab(
          label: 'Transaction History',
          icon: const Icon(Icons.history),
          content: const TransactionHistoryView(),
          enabled: false, // Tab visually and functionally disabled
        ),
      ],
    );
  }
}
```

## API Reference (Props)

### JustTabs

| Property         | Type                 | Default               | Description                                                                                       |
| ---------------- | -------------------- | --------------------- | ------------------------------------------------------------------------------------------------- |
| `tabs`           | `List<JustTab>`      | _Required_            | Array of tab objects containing label, icon, content, and status for each panel.                  |
| `variant`        | `JustTabVariant`     | `JustTabVariant.line` | Visual tab style: `.line`, `.enclosed`, `.pill`, or `.vertical`.                                  |
| `controller`     | `JustTabController?` | `null`                | External controller to manage active index synchronization programmatically.                      |
| `isScrollable`   | `bool`               | `false`               | Determines whether the tab title bar can be scrolled horizontally if the title text is very long. |
| `style`          | `JustTabsStyle?`     | `null`                | Per-instance visual overrides for colors, typography, padding, indicator, and bottom hairline.    |
| `semanticsLabel` | `String?`            | `null`                | Accessible label announced for the tablist container (`SemanticsRole.tabBar`).                    |
| `showContent`    | `bool`               | `true`                | Whether to render the tab content pages alongside or below the tab bar.                           |

### JustTab

| Property  | Type      | Default    | Description                                                                  |
| --------- | --------- | ---------- | ---------------------------------------------------------------------------- |
| `label`   | `String`  | _Required_ | Title text displayed on the tab button bar.                                  |
| `content` | `Widget`  | _Required_ | Page content widget displayed when the tab is active.                        |
| `icon`    | `Widget?` | `null`     | Optional icon widget beside the label text.                                  |
| `badge`   | `Widget?` | `null`     | Optional badge widget (such as `JustBadge.dot`) for tab notification status. |
| `enabled` | `bool`    | `true`     | Determines whether the tab can be clicked and activated.                     |

### JustTabsStyle

`JustTabsStyle` lets you override per-instance padding, colors, typography, indicator dimensions, container radius, and bottom hairline borders:

| Property            | Type      | Default | Description                                                                                                                      |
| ------------------- | --------- | ------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `borderBottomColor` | `Color?`  | `null`  | Custom bottom hairline color for the tab bar container (for example on `JustTabVariant.line`).                                   |
| `borderBottomWidth` | `double?` | `null`  | Custom bottom hairline width for the tab bar container (defaults to `presetTokens.borderWidth` when `borderBottomColor` is set). |

## Theming & Accessibility

### Preset & Style Customization

- **Default Preset**: Uses a smooth underline sliding effect (`JustTabVariant.line`). On `.enclosed` and `.pill` variants, active switching uses a background color fade transition controlled by `JustDuration.normal` and `JustCurves.default_`. You can add a custom bottom hairline on `.line` tabs with `JustTabsStyle.borderBottomColor` and `JustTabsStyle.borderBottomWidth`.
- **Neobrutalism Preset**: Under the neobrutalism preset, tab border edges on `.enclosed` and `.pill` variants use solid `colors.textPrimary` with `presetTokens.borderWidth`. Motion profiles resolve faster for crisp transitions without visual jitter.

### WCAG AA Compliance

- **Lazy Loading & Caching**: To maintain rendering performance on low-specification devices, `JustTabs` tracks visited indices in `Set<int> _visitedIndices`. Unvisited content pages return `SizedBox.shrink()`, and once opened, pages are preserved via `AutomaticKeepAliveClientMixin` so subsequent switches avoid state recreation.
- **Indicator Geometry Calculation**: The active indicator position is measured dynamically using `GlobalKey` and linearly interpolated across tab offsets for accurate sliding transitions.
- **WAI-ARIA Roving Tabindex & Keyboard Navigation**: The tablist exposes a single `Tab` stop by marking inactive tabs with `skipTraversal: true`. Pressing `ArrowLeft`/`ArrowRight` (or `ArrowUp`/`ArrowDown` in `JustTabVariant.vertical`) as well as `Home`/`End` moves both keyboard focus and selection while skipping disabled tabs (`enabled: false`). Key repeat (`KeyRepeatEvent`) is supported while holding navigation keys, and `Enter`/`Space` activates the focused tab.
- **Focus Indicator, Semantics & Reduced Motion**: Focused tabs display a visible keyboard `FocusIndicator`. The header bar exposes `SemanticsRole.tabBar` (with optional `semanticsLabel`), and each item exposes `SemanticsRole.tab` with `selected`, `enabled`, and `excludeSemantics: true`. Active text-to-background contrast meets >= 4.5:1, and reduced motion resolves `animations.resolve(context)` to `Duration.zero` so page switches jump immediately via `jumpToPage`.
