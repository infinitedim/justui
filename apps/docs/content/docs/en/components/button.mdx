The main element for triggering actions. `JustButton` carries a label, optional leading and trailing widgets, and a built-in loading state. `JustIconButton` is the icon-only sibling. Neither depends on Material.

## Playground

Change a prop and watch the button and the Dart code update.

## Add to your project

The CLI writes the source into your components directory. It does not touch `pubspec.yaml`.

```bash
justui add button
```

## Usage

### Basic

```dart
import 'package:flutter/material.dart';
import 'package:just_ui_core/just_ui_core.dart';
import 'package:just_ui_tokens/just_ui_tokens.dart';

Widget buildBasicButtons(BuildContext context) {
  return Row(
    spacing: context.justSpacing.md,
    children: [
      // Standard JustButton
      JustButton(
        label: 'Save',
        onPressed: () => print('Button pressed'),
      ),

      // Standard JustIconButton
      JustIconButton(
        icon: const Icon(Icons.share),
        tooltip: 'Share this document',
        onPressed: () => print('Share clicked'),
      ),
    ],
  );
}
```

### Sizes, icons, loading, full width

```dart
import 'package:flutter/material.dart';
import 'package:just_ui_core/just_ui_core.dart';
import 'package:just_ui_tokens/just_ui_tokens.dart';

Widget buildAdvancedButtons(BuildContext context) {
  return Column(
    spacing: context.justSpacing.lg,
    children: [
      // Destructive Button with Front Icon
      JustButton(
        label: 'Delete Account',
        variant: .destructive,
        size: .lg,
        leading: const Icon(Icons.delete_outline),
        onPressed: () => _showDeleteDialog(context),
      ),

      // Button in Loading State (Displays Progress Spinner)
      JustButton(
        label: 'Processing...',
        isLoading: true,
        onPressed: () {},
      ),

      // Full Width Button
      JustButton(
        label: 'Proceed to Payment',
        isFullWidth: true,
        size: .xl,
        trailing: const Icon(Icons.arrow_forward),
        onPressed: () => _proceedToPayment(),
      ),
    ],
  );
}
```

class CheckoutActions extends StatefulWidget {
  const CheckoutActions({super.key});

  @override
  State<CheckoutActions> createState() => _CheckoutActionsState();
}

class _CheckoutActionsState extends State<CheckoutActions> {
  bool _paying = false;
  bool _paid = false;

  Future<void> _pay() async {
    setState(() => _paying = true);
    await api.charge(amount: 49.00);
    setState(() {
      _paying = false;
      _paid = true;
    });
  }

  @override
  Widget build(BuildContext context) {
    return Column(
      spacing: context.justSpacing.md,
      children: [
        JustButton(
          label: _paid ? 'Paid' : 'Pay now',
          isLoading: _paying,
          isDisabled: _paid,
          isFullWidth: true,
          size: .lg,
          trailing: const Icon(Icons.lock_outline),
          onPressed: _pay,
        ),
        Row(
          spacing: context.justSpacing.sm,
          children: [
            Expanded(
              child: JustButton(
                label: 'Save draft',
                variant: .secondary,
                isFullWidth: true,
                onPressed: _saveDraft,
              ),
            ),
            JustIconButton(
              icon: const Icon(Icons.close),
              tooltip: 'Discard order',
              variant: .destructive,
              onPressed: _confirmDiscard,
            ),
          ],
        ),
        JustButton(
          label: 'Need help?',
          variant: .link,
          onPressed: _openSupport,
        ),
      ],
    );
  }
}

## API reference

### JustButton

| Property       | Data Type           | Default Value | Description                                                                                                                   |
| :------------- | :------------------ | :------------ | :---------------------------------------------------------------------------------------------------------------------------- |
| `label`        | `String`            | _Required_    | Text displayed inside the button.                                                                                             |
| `onPressed`    | `VoidCallback?`     | _Required_    | Callback when the button is pressed. If `null`, the button is automatically disabled visually and interactively.              |
| `variant`      | `JustButtonVariant` | `.primary`    | Button visual style options: `.primary`, `.secondary`, `.ghost`, `.destructive`, `.link`.                                     |
| `size`         | `JustButtonSize`    | `.md`         | Button geometry size: `.xs`, `.sm`, `.md`, `.lg`, `.xl`.                                                                      |
| `leading`      | `Widget?`           | `null`        | Widget (usually an icon) placed before the label text.                                                                        |
| `trailing`     | `Widget?`           | `null`        | Widget (usually an icon) placed after the label text.                                                                         |
| `isLoading`    | `bool`              | `false`       | Determines whether the button is in a loading process. If `true`, text/icon is hidden and `JustProgressSpinner` is displayed. |
| `isDisabled`   | `bool`              | `false`       | Disables button interaction and provides a dimmed visual when set to `true`.                                                  |
| `isFullWidth`  | `bool`              | `false`       | Stretches the button horizontally to fill the container when set to `true`.                                                   |
| `style`        | `JustButtonStyle?`  | `null`        | Overrides the button design style specifically per instance.                                                                  |
| `enableHaptic` | `bool?`             | `null`        | Enables light haptic feedback when the button is pressed. Defaults to active when using the `neobrutalism` preset.            |

### JustIconButton

| Property       | Data Type           | Default Value | Description                                                                               |
| :------------- | :------------------ | :------------ | :---------------------------------------------------------------------------------------- |
| `icon`         | `Widget`            | _Required_    | Icon widget to be displayed in the center of the button.                                  |
| `onPressed`    | `VoidCallback?`     | _Required_    | Callback when the button is pressed. If `null`, the button is automatically disabled.     |
| `variant`      | `JustButtonVariant` | `.ghost`      | Button visual style options: `.primary`, `.secondary`, `.ghost`, `.destructive`, `.link`. |
| `size`         | `JustButtonSize`    | `.md`         | Button geometry size: `.xs`, `.sm`, `.md`, `.lg`, `.xl`.                                  |
| `tooltip`      | `String?`           | _Required_    | Semantic button description for screen readers (accessibility) and hover tooltip balloon. |
| `isLoading`    | `bool`              | `false`       | If `true`, hides the icon and displays a loading indicator.                               |
| `isDisabled`   | `bool`              | `false`       | Disables interaction and dims the display when set to `true`.                             |
| `style`        | `JustButtonStyle?`  | `null`        | Overrides the icon button design style specifically.                                      |
| `enableHaptic` | `bool?`             | `null`        | Enables light haptic feedback when the button is pressed.                                 |

## Accessibility

1. **Minimum touch targets.** Even when the button size is set to `.xs` or `.sm`, JustUI guarantees the interactive touch target area still has a minimum physical size of **48x48px** according to WCAG AA guidelines. This is implemented internally through a `ConstrainedBox` wrapper and an expanded hit-test area.
2. **Mandatory semantic description.** For `JustIconButton`, the `tooltip` parameter must be provided (`assert(tooltip != null)`). This ensures that screen readers can announce the button function description to users with visual impairments.
3. **Visible focus indicator.** When the button is accessed using a keyboard or other controller, a thick, high-contrast focus indicator is displayed around the button through the internal `FocusIndicator` helper widget.
4. **Automatic icon coloring.** Through `IconTheme.merge`, icon colors are automatically adjusted to match the contrast color of the active button status (for example, becoming high-contrast white when the primary button is active, or pale gray when disabled).
