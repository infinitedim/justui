# Quick Start

Welcome to the JustUI quick start guide! In less than 5 minutes, you will learn how to set up the JustUI design system in your new Flutter application, configure visual presets, and use your first component.

## Prerequisites

Before starting, make sure you have completed the steps on the [Installation](/docs/installation) page:

1. Activate the CLI tool globally: `dart pub global activate just_ui_cli`
2. Run initialization: `justui init` in your Flutter project root.

---

## Step 1: Setup Provider in the Root Widget

JustUI uses `JustThemeProvider` to manage theme modes (light, dark, or system) and distribute theme data efficiently using _Aspect-Based Rebuilds_.

Open your application's entry point file (usually `lib/main.dart`) and wrap your root widget with `JustThemeProvider`:

```dart
import 'package:flutter/widgets.dart';
import 'package:just_ui_core/just_ui_core.dart';
import 'theme/just_theme.dart'; // Theme file generated by the CLI

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return JustThemeProvider(
      initialThemeMode: ThemeMode.system,
      // Use the default theme or customize as needed
      lightTheme: JustThemeData.light,
      darkTheme: JustThemeData.dark,
      child: const HomeScreen(),
    );
  }
}
```

> **Note**: If your project still uses MaterialApp for navigation or built-in Flutter utilities, you can easily integrate JustUI theme data into Material `ThemeData` using the `.toThemeData()` extension:
>
> ```dart
> MaterialApp(
>   theme: JustThemeData.light.toThemeData(),
>   darkTheme: JustThemeData.dark.toThemeData(),
>   themeMode: ThemeMode.system,
>   home: const HomeScreen(),
> )
> ```

## Step 2: Using a Visual Preset

JustUI supports two main visual presets that can be configured during initialization or changed dynamically on `JustThemeData`:

1. **Default Preset (`JustThemePreset.default_`)**: A modern, clean design with soft rounded corners and gentle shadows.
2. **Neobrutalism Preset (`JustThemePreset.neobrutalism`)**: A bold aesthetic with thick borders (2.5px), sharp corners, solid flat-offset shadows, and high color contrast (deep black in light mode, stark white in dark mode).

Example initialization using the **Neobrutalism** preset:

```dart
import 'package:flutter/widgets.dart';
import 'package:just_ui_core/just_ui_core.dart';

// Inside main.dart or your theme configuration file
final neobrutalismTheme = JustThemeData(
  colors: JustColors.neobrutalismLight(),
  shadows: const NeobrutalismShadowScheme(),
  preset: JustThemePreset.neobrutalism, // Using the neobrutalism preset
);
```

## Step 3: Adding and Using Your First Component

Let's add the button component (`JustButton`) to your project using the CLI:

```bash
justui add button
```

The CLI will download and copy the `JustButton` source code into your component folder (for example, `lib/components/ui/button.dart`).

Now, you can directly import and use the button in your page widget.

### Example Usage of `JustButton`

Use _Dart Dot Shorthand_ for Flutter built-in parameters (such as `.symmetric` or `.all`) to align with JustUI's coding style:

```dart
import 'package:flutter/material.dart' show Icons;
import 'package:flutter/widgets.dart';
import 'package:just_ui_core/just_ui_core.dart';
import 'components/ui/button.dart'; // Adjust to your import path

class HomeScreen extends StatelessWidget {
  const HomeScreen({super.key});

  @override
  Widget build(BuildContext context) {
    // Access color, spacing, and radius tokens from context
    final colors = context.justColors;
    final spacing = context.justSpacing;

    return Container(
      color: colors.background,
      padding: .all(spacing.lg), // Dart Dot Shorthand
      child: Center(
        child: Column(
          mainAxisAlignment: .center,
          children: [
            // 1. Primary Button
            JustButton(
              label: 'Get Started',
              onPressed: () {
                print('Button pressed!');
              },
            ),
            const SizedBox(height: 16),

            // 2. Loading Button with Leading Icon
            JustButton.secondary(
              label: 'Downloading Data',
              leading: const Icon(Icons.download),
              isLoading: true,
              onPressed: () {},
            ),
          ],
        ),
      ),
    );
  }
}
```

### Important Theme Consumption Rules:

- **Use specific aspects** inside the `build` method: `context.justColors` for colors, `context.justSpacing` for spacing, and `context.justTypo` for typography. This ensures your widget only rebuilds when the aspect it uses changes.
- **Use the non-registering API** inside interaction callbacks (such as `onPressed`): use `context.readTheme()` instead of active getters to avoid unnecessary widget tree rebuilds.
