The JustUI typography system is designed to produce outstanding readability across various screen sizes. Using the modern sans-serif typeface **Inter** as the default interface font and **JetBrains Mono** for numeric data or programming code elements, JustUI supports both static scaling and responsive (fluid) typography scaling.

---

## 1. Font Family

JustUI supports two main font families:

- **Default Sans-Serif (`JustTypo.fontFamily`)**: Uses the **Inter** font. An ideal choice for clean, neutral, and professional UI.
- **Monospace (`JustTypo.monoFontFamily`)**: Uses the **JetBrains Mono** font. Highly suitable for displaying code snippets, log numbers, financial data, or densely formatted metadata tags.

---

## 3. Fluid Typography (`JustFluidTypography`)

To prevent large-sized text from dominating the mobile device viewport or appearing too small on wide desktop monitors, JustUI provides a **Fluid Typography** system through the `JustFluidTypography` extension.

This system stretches text size linearly (linear interpolation) between minimum screen width (`minWidth`) and maximum screen width (`maxWidth`).

### Fluid Typography Mathematical Formula

Scaling is calculated at runtime using the formula:

```text
fontSize = minSize + ((maxSize - minSize) / (maxWidth - minWidth)) * (clampedWidth - minWidth)
```

Where:

- `minWidth` is set by default to `640.0` px (`JustBreakpoints.sm`).
- `maxWidth` is set by default to `1024.0` px (`JustBreakpoints.lg`).
- `clampedWidth` is the current active viewport screen width clamped within the `minWidth` and `maxWidth` range.

### `fluid()` Method

This extension method on `TextStyle` returns a new instance with a dynamically calculated font size based on the current screen size:

```dart
// Example of applying fluid to any TextStyle
TextStyle fluidStyle = JustTypo.displayLg.fluid(
  screenWidth: MediaQuery.sizeOf(context).width,
  minSize: 36.0,
  maxSize: 48.0,
);
```

## 4. Dynamic Line Height Adaptation (`withAdaptiveHeight`)

Good readability requires line height that is proportional to text size:

- **Small Text**: Requires more generous line height so the eye can easily read between words without fatigue.
- **Large Text**: Requires tighter line height so text lines don't feel fragmented and remain visually solid.

JustUI implements this adjustment dynamically through the `.withAdaptiveHeight(context)` method. Its evaluation procedure is:

1. Takes the base font size (`fontSize`, default: `16.0`).
2. Applies the user's operating system accessibility text scale (`MediaQuery.textScalerOf(context).scale(baseSize)`).
3. Performs the new line height calculation:
   - If the measured font size is **≤ 12.0 px**, line height is set generous: **`1.6`**.
   - If the measured font size is **≥ 36.0 px**, line height is set tight: **`1.15`**.
   - For font sizes in between, line height is interpolated linearly.

---

## 5. Fluid Typography Presets (`JustFluidTypo`)

For ease of implementation, JustUI provides the `JustFluidTypo` helper class presets. This class automatically tracks container screen width and applies fluid calculation along with adaptive line height adjustment instantly.

You simply call the instance function by passing `BuildContext`:

```dart
// Available presets in JustFluidTypo:
TextStyle fluidLg = JustFluidTypo.displayLg(context); // Scaling 36px ↔ 48px
TextStyle fluidMd = JustFluidTypo.displayMd(context); // Scaling 30px ↔ 38px
TextStyle fluidSm = JustFluidTypo.displaySm(context); // Scaling 24px ↔ 32px
TextStyle headLg  = JustFluidTypo.headingLg(context); // Scaling 20px ↔ 24px
TextStyle headMd  = JustFluidTypo.headingMd(context); // Scaling 18px ↔ 20px
TextStyle headSm  = JustFluidTypo.headingSm(context); // Scaling 16px ↔ 18px
TextStyle bodyLg  = JustFluidTypo.bodyLg(context);    // Scaling 15px ↔ 16px
TextStyle bodyMd  = JustFluidTypo.bodyMd(context);    // Scaling 13px ↔ 14px
TextStyle bodySm  = JustFluidTypo.bodySm(context);    // Scaling 11px ↔ 12px
```

## 6. Best Practice Example for Consuming Typography in Flutter

To maintain optimal widget tree rendering performance, use the `justTypo` context aspect inside the `build()` method. This minimizes widget rebuilds if other theme parameters (such as colors) change.

```dart
class TextCardWidget extends StatelessWidget {
  const TextCardWidget({super.key});

  @override
  Widget build(BuildContext context) {
    // Registering widget ONLY on the typography aspect
    final typo = context.justTypo;

    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        Text(
          'This is a Page Title',
          style: typo.headingLg.copyWith(
            color: context.justColors.textPrimary,
          ),
        ),
        const SizedBox(height: 8.0),
        Text(
          'This is a clean supporting card paragraph body using Inter.',
          style: typo.bodyMd.copyWith(
            color: context.justColors.textSecondary,
          ),
        ),
      ],
    );
  }
}
```
