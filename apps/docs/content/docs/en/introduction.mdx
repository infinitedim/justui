# Introduction

**JustUI** is a collection of Flutter UI components designed with premium aesthetics, high accessibility, and maximum performance. JustUI is not installed as a third-party package but instead uses a **copy-paste** workflow inspired by shadcn/ui.

## Why JustUI?

1. **Zero-Dependency Footprint**: JustUI components do not rely on third-party pub.dev packages beyond the built-in Flutter SDK.
2. **Full Customization**: Because the component source code lives directly in your project, you are free to change parameters, visuals, and logic without any limitations.
3. **Modern Design**: Provides advanced visual presets, including the **Neobrutalism** style with sharp contrasts, solid shadows, and smooth transitions.
